# 立ち絵

長編(16:9)の対話動画で使う。`generate_longform.py --portrait-dir` の既定の置き場。

ファイル名は VOICEVOX の話者名そのまま。`generate_longform.SPEAKERS` の
`name` で引いているので、名前を変えると絵が出なくなる(丸で代用される)。

| ファイル | 元 | 大きさ |
|---|---|---|
| `ずんだもん.png` | ずんだもん立ち絵素材改 1.1.1 | 741×1472 |
| `四国めたん.png` | 四国めたん立ち絵素材 2.1 | 858×1769 |

いずれも PSD から合成して、透明の余白を落としたもの。

**この2つを選んだのは、規約が文章で明記されているから。**
同じ配布元の PNG 版(`ずんだもん立ち素材.zip` / `めたん立ち素材1.01.zip`)は
そのまま使える PNG が入っていて手間は少ないが、同梱されているのは
キャラクター表の画像で、利用条件が書かれていない。
毎日自動で投稿する仕組みに、条件の分からない素材は入れない。

キャラクター自体の規約は東北ずん子・ずんだもん公式および
VOICEVOX 四国めたんに従う。音声も同じキャラクターを使っているので、
動画の隅に `音声: VOICEVOX ずんだもん / 四国めたん` を常時出している
(`generate_longform.render_line`)。

## 部品

PSDに目(閉じ目つき)・眉・口が別の層で入っていたので、
`scripts/build_portrait_parts.py` で切り出してある。

```
assets/portraits/<名前>/
  体.png       目・眉・口を消した下地
  目_開 目_閉 目_笑 目_見開 目_ジト
  眉_基本 眉_上げ 眉_困り
  口_閉 口_開 口_笑 口_大
  右腕_基本 右腕_上げ 右腕_考え 右腕_指
  左腕_基本 左腕_上げ 左腕_考え 左腕_指
  parts.json   どれが何か
```

**どれも全画面の大きさ**なので、(0,0)に重ねるだけでよい。ずれようがない。

これで、

- **まばたき** … 2.6〜5.2秒に1回、0.12秒。名前を種にして揺らす
- **口の動き** … 読み上げの音の大きさから取る（`video_common.mouth_levels`）。喋っている側だけ動く
- **表情** … 台詞から引く（`generate_longform.expression_for`）。問いかけは眉を上げる
- **腕** … 表情に合わせて変わる。驚けば手が上がり、困れば顎に指がいく

が出せる。

部品を作り直すときだけ psd-tools が要る（`pip install psd-tools`）。
動画を作る側は出来上がったPNGを重ねるだけなので、GitHub Actions には要らない。

### 全差分の部品（2026-10-27）

旧21枚ずつの名前・内容・JSONの旧キーは保持。新部品は `差分_` で始まる。
元PSDは含めない。製作・利用条件は上記と同じ。

| 対象 | 新PNG数 | キャンバス | 内容 |
|---|---:|---|---|
| 四国めたん | 71 | 1082×1820 | 目19（うち目セット12）・眉7・口13・顔色6・腕8・小物2・体/服6・髪/輪郭4・装飾4・汗涙2 |
| ずんだもん 共通 | 24 | 1082×1552 | 体2・右腕12・左腕10（腕組みは両腕が入った1枚） |
| ずんだもん 正面 | 42 | 1082×1552 | 頭下地1・枝豆2・顔色4・口13・目15・眉5・汗涙2 |
| ずんだもん 上向き | 38 | 1082×1552 | 頭下地1・枝豆3・顔色4・口13・目10・眉5・汗涙2 |

上向きだけ `<名前>/上向き/` に保存。それ以外は従来の名前フォルダ。
透明の「非表示」も元PSDの選択肢として含む。めたんの白目2種×黒目6種は、
PSDの表示順で合成して12枚の目セットにした。PSDに単独ハイライト層は無い。

`parts.json` の `catalog` は全新部品の `category`（部位）、`source_layers`（元層の完全経路）、
`meaning`（明確でないものは「未定」）、`direction`、`order`（下から上）、
`exclusive_group`、`requires`、`forbids`、非透明範囲とSHA256を収録。
`legacy_metadata` は旧21枚の由来。上向きのJSONから共通部品は `../parts.json` を参照する。
APSCと同じ `eye/brow/mouth/cheek/fx/arm_front/arm_back/head/outfit` にも、向き別のファイル索引を持つ。
`arm_front` はPSDの上側に描かれる左腕、`arm_back` は下側の右腕。小物は追加の `prop`。
`rules` には排他グループ・向き・必要部品・禁止部品を機械で読める形で収録する。

新部品は透明のキャンバスから選び、`order` の昇順に原点(0,0)で重ねる。
旧「体」は顔色・髪・装飾も焼込み済みなので、新しい顔色や頭下地を重ねる用途には使わない。
正面と上向きの顔は混ぜず、各部位を1枚ずつ選ぶ。ずんだもんの腕組みは右腕を外す。
めたんの別衣装は素体＋衣装で白ロリ服と排他、白ロリ用腕も外す。
髪留めのハートとフリルは排他。他の装飾・小物は個別に選べる。
ポニテ用の髪は元座標のまま保存しており、作者の注記通り回転・移動が必要。

再生成は `python scripts/export_all_portrait_parts.py --source <PSDディレクトリ>`。
一覧だけなら `python scripts/export_all_portrait_parts.py --review-only`（PSD不要）。psd-tools 1.18で抽出。

### APSCと共通の部位名・組合せ（10/27追記）

`eye/brow/mouth/cheek/fx/arm_front/arm_back/head/outfit` は各人物のparts.jsonの索引。
値はキャラごとに異なるため、そのJSONから選ぶ。headは正面/上向きの系統、
outfitは体・服、前腕/奥腕はPSDの描画順（左腕/右腕）。小物はprop。
上向き/parts.jsonは顔だけの索引。共通の体・腕を含む全身には親のparts.jsonを使う。

表情・ポーズの値もparts.jsonの`presets`が正本。報告用のproposals.jsonはその写し。
一覧生成器にキャラ別の部品名・表情の値は持たせない。
`portrait_parts.compose_parts(folder, data, files, context='平時')` はPNGを開く前に
JSONのrulesで向き混在・同部位重複・必要部品・禁止部品・腕の組を検査し、違反をValueErrorで止める。
白目と黒目は合成済みの目セットだけを選ぶ。指さしは同時1本、両手は待機＋1動作か同じ意味の組だけ。
腕組みでは奥腕の描画を外す（透明な非表示部品は可）。

目のcatalogに`mood`を持つ。ハイライトのない虚ろな黒目は`非平時`とし、
異変・不穏・呆然・夢うつつ・催眠/洗脳ネタ・不気味のcontextだけで使う。
普段の感情と事実の行では使わない（本人10/27）。閉じ目や白目だけの記号目は別。
実動画の既存描画への接続は今回行っていない。
表情・ポーズの提案と一覧は `build_reports/portrait_parts_20261027/`、
判断・確認結果は `build_reports/portrait_parts_20261027.md` を参照。
本番の長編・ショートの描画にはまだ接続していない。

### 10/27 APSC共通形式と選択方針（上記の目の分類を更新）

`mood: 非平時` はハイライトの無い虚ろな目だけ。めたんは見上げ2と、
目そらし2・カメラ目線2・普通目2×白目2種の計7セット。
元層の `!目/*目セット/!黒目` の3種を収録済み。
拡大した実物には濃色の小点が残るため「瞳孔が無い」とは断定しない。
ずんだもんは正面・上向き全25種を一覧で確認し、同型は無し。
見開き・三白眼と○○は `emphatic_eyes` に移した。
めたんの○○・ぐるぐると両人物の＞＜も同区分。非平時とは独立した属性で、混乱・がーん等の強い反応に使える。
`validate_parts` は事実の行（`factual=True` またはcontext='事実'）と聞き手（`listener=True`）では
非平時とemphatic_eyesを拒否する。目の意味を台詞から自動判定するものではない。

めたんの白ロリ服は既定。水着・バニー服・バスタオル・素体（透明衣装も含む）は必要時のみ。
`validate_parts` / `compose_parts` は既定の `automatic=True` で必要時のみを拒否する。
これはスポーツ情報チャンネルであるコレスポ側の使い方の決まり。
手動で場面や台本がはっきり求め、本人へ見本を見せて使う場合だけ `automatic=False` とする。
素材の削除や利用不能化はしない。既存本番描画には今回も未接続。

各人物の `common.parts.json` は、雨衣と同じ `parts/defaults/presets/order/rules` の共通形式。
`rules` は配列、部品値はファイル名または配列。元catalog版の `parts.json` は互換性のため保持。
髪・装飾・かげり・小物の重ね順用に `hair_* / head_* / cheek_shadow / prop_*` の追加部位を使う。
共通道具は任意の部位キーを読めるため、道具本体の変更は不要。
素体＋衣装はoutfitの1選択にまとめ、全新部品を選択可能にした。

## 向き

素材はどちらも同じ向きに描かれている。そのまま左右に置くと、片方が外を向く。
`generate_longform.SPEAKERS` の `flip` で、左側のずんだもんだけ反転している。
