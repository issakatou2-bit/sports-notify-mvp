Threads連携

コレスポが選んだ注目試合を、コレスポ自身のThreadsアカウントへ 自動投稿するための設定です。運営者向けの画面です。

1. アプリ情報

Meta開発者ポータルの Threads app ID を入れます。 Facebookアプリ側のIDとは別物なので取り違えないでください。 この値は公開されても問題のないもので、この端末にだけ保存されます。 App secret はここでは扱いません。

2. Threadsにログインして許可する

Threadsの画面に移動します。コレスポのアカウントでログインし、 投稿を許可してください。

3. このあとの流れ

  1. 許可すると /threads/callback.html に戻ります
  2. そこに表示される認可コードを控えます
  3. 手元で scripts/threads_auth.py を実行して 長期トークン(60日)に交換します
  4. そのトークンを GitHub Secrets の THREADS_ACCESS_TOKEN に登録します

トークンは投稿のたびに自動で延長されるので、毎日動いている限り 切れません。TikTokと違って投稿ごとの確認画面は要らず、完全に自動で 投稿されます。
