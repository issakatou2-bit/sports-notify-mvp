TikTok連携

コレスポが自動生成した動画を、コレスポ自身のTikTokアカウントへ 投稿するための連携設定です。運営者向けの画面です。

1. アプリ情報

TikTok Developer Portal の Client key を入れます。 この値は公開されても問題のないもので、この端末にだけ保存されます。 Client secret はここでは扱いません。

審査が通るまでこの権限は付与されません。 承認前にチェックを入れると、TikTokのログイン画面が 「エラーが発生しました … scope」で止まります。 ふだんは外したままにしてください。

2. TikTokにログインして許可する

TikTokの画面に移動します。コレスポのアカウントでログインし、 動画の投稿を許可してください。

3. このあとの流れ

  1. 許可すると /tiktok/callback.html に戻ります
  2. そこに表示される認可コードを控えます
  3. 手元で scripts/tiktok_auth.py を実行して リフレッシュトークンに交換します
  4. そのトークンを GitHub Secrets の TIKTOK_REFRESH_TOKEN に登録します

以降は毎日の自動投稿がこのトークンを使います。 トークンの有効期限は1年で、投稿のたびに自動で更新されます。
