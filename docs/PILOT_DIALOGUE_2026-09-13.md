# 解説2本の掛け合い・音声改訂

ユーザー依頼により、CLと国内リーグ／同じ2安打の試作を第2稿に改訂。ずんだもんが疑問を出し、めたんが答える。プレミアリーグとラ・リーガを具体例として発話・画面に追加し、冒頭と末尾で「コレスポ」を短く読む。

めたんのpitchScaleは0.035。速度は旧設定の1.1倍（CL 1.14→1.254、野球1.12→1.232）。全セリフの話者と音声設定を対応させ、画面上部に読み手を表示。説明欄と終端画面は両話者のVOICEVOXクレジットを表示する。既存の図・野球の写真・架空の試合例という明示を維持。

独自立ち絵は別作業。利用枠の見通しが立ってから制作するという最新指示に従い、今回は追加生成しない。希望は「以前の親しみやすい雰囲気、ユニフォームを可愛く着こなすデフォルメ」。全身の写実性より、動画サイズで表情が読み取れ、MLBとサッカーの両方に合うことを重視する。

原稿は手元で改訂した固定JSON。Anthropic等の有料原稿API呼び出しは追加しない。VOICEVOXを既存Actionsで実行する。Actions利用枠の消費はあるため無費用を保証しない。

重複防止番号は改訂稿と旧版を区別する。確認後に人が公開へ変更した投稿済み回は、そのまま次回の制作対象から除く。未確認の公開動画・所有者不一致・照合不能は停止し、既存動画の公開状態を自動変更しない。新規制作は引き続きprivate固定。
