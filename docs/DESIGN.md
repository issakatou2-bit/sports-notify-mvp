# コレスポの見た目

**この文書を書いたきっかけ**は、YouTubeサムネイル用フォントの記事と、
「DESIGN.md をAIに渡せば汎用的な見た目から脱却できる」という
`styles.refero.design` の紹介でした。

そこで**自分の側を数えてみたら、問題は書体ではありませんでした。**

```
7本の動画台本が使っている文字の大きさ …… 40種類 / 360箇所
  22 24 26 28 30 32 34 36 38 40 42 44 46 48 50 52 54 56 58 60 62 64
  66 70 72 74 76 80 84 88 96 104 112 120 124 132 140 150 180 240

隣り合う刻みのうち 33件が 1.08倍未満
直書きの色 …………………………………… 52種類 / 129箇所
```

**26と28は、並べてもどちらが大きいか分かりません。**
大きさが40種類あるのに、見分けがつく段は10も無い。
「なんとなく素っ気ない」の正体はここだと思っています。
大小の差が付いていないので、どこを見ればいいか目が決められない。

書体は既に**源ノ角ゴシック Heavy（Noto Sans CJK Black）**で、
これは「YouTubeサムネにいちばん薦められている書体」そのものでした。
替える必要はありません。

---

## 文字の階段

`video_common.TYPE_SCALE`。1.25倍ずつ。**1段違えば必ず見分けがつく。**

| 大きさ | 使うところ |
|---:|---|
| 20 | 補足の最小 |
| 26 | 出典・クレジット・話者の名前 |
| 32 | ラベル・話題・札の見出し |
| 40 | 小さめの本文 |
| 50 | 本文（台詞） |
| 64 | 小見出し |
| 80 | 見出し |
| 100 | 大きい数字（再生回数・防御率） |
| 124 | 主役 |
| 156 | サムネイルの主役 |
| 196 | いちばん大きい |

階段の外の値は `video_common.type_size(n)` で丸める。

**いま揃っているのは長編とその サムネイルだけ。**
既にある7本を一度に揃えると、全部の画面が同時に変わって
何が効いたのか分からなくなります。新しいものから使い、
古いほうは `run_checks` が数えて出すだけにしてあります。

## 色

| 名前 | 値 | 役目 |
|---|---|---|
| `BG` | `#0B0E14` | 下地 |
| `SURF` | `#12161F` | 箱 |
| `PANEL_BG` | `#161B26` | 情報の札（箱より少し明るい） |
| `PANEL_EDGE` | `#2C3446` | 札の縁 |
| `TEXT` | `#F2F0E6` | 本文 |
| `DIM` | `#8891A3` | 添え物 |
| `ACCENT` | `#FFB020` | 主役・勝ったほう |
| `JP` | `#49C5B6` | 日本人選手・コレスポ |

**52種類の直書きが残っています。** 名前の付いた8色を各ファイルが
自前で書き直しているのが大半で、寄せる価値はありますが、
色を寄せると全画面が同時に変わるので、文字の階段と同じ理由で
段階的にやります。

## サムネイルの文字

書体ではなく**処理**で決まります。`video_common.pop_text`。

- **太い縁取り**（10px）で背景から切り離す
- **少しずらした影**（6,7px）で浮かせる
- **1語だけ色を変える**（「読み解く」だけ `ACCENT`）

縁取りには実利もあります。**立ち絵の上に文字が乗っても読める**ので、
重なりを避けるために画面を狭くしなくて済みます。

そして**大きい文字は毎日同じにする。**長さが変わるもの（対戦カード）は
上の小さい行へ回す。これで球団名が長い日でも被りません。

## 他所のデザインシステムを持ってこないのはなぜか

`styles.refero.design` は Linear や Notion の色・字・余白を
そのまま `DESIGN.md` として配っていて、無料で登録も要りません。
道具としてはよくできています。

**それでも持ってきません。**

1. **あれは web の UI の話。** ボタン、フォーム、ホバー、余白。
   1080pの動画をスマホで腕の長さから見るのとは、
   文字の大きさも要る対比も違う
2. **他所の見た目をそのまま着ると、その他所に見える。**
   コレスポは公開しているチャンネルで、見た目は名前と同じく
   その番組のもの。Linearの色を着たら Linear に見える
3. **いま足りないのは色や書体ではなく、階段だった。**
   数えて分かった。他所から借りても、40種類が別の40種類に
   なるだけで直らない

**借りたのは考え方のほうです。**「1つの文書に token をまとめる」。
それがこの文書です。

## サムネイル（2026-08-31 に作り直した）

**題とサムネイルは役割が違う。**

| | 担当 | 入れるもの |
|---|---|---|
| **題** | 検索に引っかかる | 「海外の反応」「選手名」——**人が打ち込む言葉** |
| **サムネイル** | 目に入った瞬間 | 題に書いても検索は増えないが、一目で知りたいもの——**日付**。あとは押す理由 |

調べた実務の目安を、そのまま当ててある。

| 目安 | いまの作り |
|---|---|
| 文字は最長20字、理想6〜8字 | 大きい2行で9字（「大谷翔平」＋「海外の反応」） |
| **重要なものは左上70%。右下30%は再生時間の表示と重なる** | 文字は全部左60%。右下は立ち絵の脚だけ |
| 色は3色まで | 白・オレンジ・青緑（本文・主役・日本人選手） |
| コントラスト比 4.5:1 以上 | 暗い下地に明るい字＋黒の縁取り |
| 大小の差をはっきり | TYPE_SCALE で 40 / 100 / 156。1.25倍ずつ |

```
[8/31] ドジャース vs タイガース   ← 日付は塗りの札。一目で最新と分かる
大谷翔平                        ← 124 / 青緑
海外の反応                      ← 156 / オレンジ（いちばん大きい）
公式コメント欄を読む              ← 40 / 添え物（縮小したら読めなくてよい）
コレスポ
```

**日付を塗りの札にしたのが要点。**「8月31日」を細い字で小さく置いていたが、
一覧の大きさ（246px幅）に縮むと読めなかった。一覧に並んだとき知りたいのは
「今日の最新か」なので、そこが読めないと置く意味が無い。「8/31」に詰めて、
塗りの中へ入れた。246pxでも読める。

**名前が取れない日は、対戦カードが大きい行へ回る。**上の小さい行と
両方に出すと、同じ言葉が2回並ぶ。

**球団名は都市名を落とす。**「サンディエゴ・パドレス vs ミルウォーキー・
ブルワーズ」は都市を入れると20字を超えて、いちばん小さい字でもはみ出した。
「パドレス vs ブルワーズ」で足りる。
