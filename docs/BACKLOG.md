## 今日の1人について

**この枠は何をする枠なのか、答えが出ていない。**

```
視聴継続 22.6%（下から2番目）
再生     40〜254回（最下位）
長さ     73秒（最長）
```

いま出しているのは「通算・今季・昨季・直近・受賞歴」で、
**Wikipediaの要約に近い**。数字は正しいが、
「へえ」も「あの選手か」も起きない。

**足りないのは、その選手を今日見るべき理由。**
候補:

- **今日なぜこの選手なのか**（MLB全体で最も活躍した、という選定理由を出す）
- **今季の中でどれくらい珍しい日だったか**（自己最高、何試合ぶり）
- **その日のコメント欄に名前が出ていたか**（`jp_mentioned` を全選手に広げれば取れる）

3つ目がいちばん効くと思う。**現地が誰の話をしていたか**は、
成績とは別の情報で、こちらしか出していない。
