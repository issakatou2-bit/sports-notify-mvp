## 今日の1人について

**この枠は何をする枠なのか、答えが出ていない。**

```
視聴継続 22.6%（下から2番目）
再生     40〜254回（最下位）
長さ     73秒（最長）
```

いま出しているのは「通算・今季・昨季・直近・受賞歴」で、
**Wikipediaの要約に近い**。数字は正しいが、
「へえ」も「あの選手か」も起きない。

**足りないのは、その選手を今日見るべき理由。**
候補:

- **今日なぜこの選手なのか**（MLB全体で最も活躍した、という選定理由を出す）

3つ目がいちばん効くと思う。**現地が誰の話をしていたか**は、
成績とは別の情報で、こちらしか出していない。

### 日本人成績ショート — 打者の本塁打が投手の完封より上に来る

名前のある記録の加点を入れたあとの並び（9/11実測）:

```
サイクル安打      210    ノーヒッター    205
2本塁打          182    完封            162
3打数1安打1本塁打  95    7回1失点10奪三振  115
```

**2本塁打（182）が完封（162）より上。**打者の土台50・倍率3.6に対して
投手は土台45・倍率1.2で、打者側が強い。名前のある記録で先発の好投は
救えたが、本塁打そのものの重みは手を付けていない。

直すなら投手の倍率を上げる（1.2→1.4）が素直。ただし**過去の点数と
比べられなくなる**（画面に「前回◯点」を出している）ので、
変えるなら前回・平均の記録も作り直すか、変えた日を記録しておく必要がある。

## 2026-09-11 長編を数字主体へ（承認済み・未着手）

ユーザーの決定:「長編を数字主体に組み替える案、これにしましょう。
いずれまた何かいいのあればそうしましょう」。

### 決まっていること

- **ずんだもんとめたんの会話は続ける**（形として残したい、とのユーザーの意向）
- 対象を「公式ハイライトのコメント欄」から変える
- 中身は**ショートの内容をつなげた形**

### なぜこの形か

コメント欄は**検算できない**。9/10の「Bassoは5日ぶりの復帰」は
数字の誤りではなく解釈の誤りで、「5日空いた」は事実、「復帰明け」が解釈。
数字を突き合わせる仕組み（`verify_numbers.py`）では捕まえられない。

数字主体なら三段目が効く。台詞の数字と材料を全部突き合わせるので、
同じ形の事故が構造的に起きない。

### 構成案

```
「今日のMLB、数字で5分」
  1. 日本人選手の成績（名前のある記録があればそこを主題に）
  2. 進出争いの動き（線をまたいだチーム）
  3. その日の記録・節目（milestones.py が既にある）
  4. 明日の見どころ
```

**材料は既に全部ある。**7本ぶんの、検算を通した数字。追加のAPI代はほぼ0。

二人いる意味は「片方が知らないこと」にある。めたんが数字を出し、
ずんだもんが「それってどういうこと？」と聞く。数字の意味を説明する役が
要るので二人必要。コメント欄では両方が「海外の反応を見て感想を言う」形で
役割が重なっていた。

   （皮肉の扱い、コメントの長短、書き込んだ人への配慮などが大半を占めている）
