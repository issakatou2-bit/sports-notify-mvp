# ショートの長さと情報量

本人の10/27指示：「ショート、情報1個ポン出しの20秒切るようなのはやめてください。ある程度情報足すとか、2次情報入れて30秒いくくらいはやってください」。

- 原則30秒程度以上、描画前の厳格な下限28秒。既存の種類別上限を守る。
- 主の事実1件に、独立した2次情報を2件以上。同じ勝敗の表紙と本文、王手と勝数、同じことの言い換えは重複として数えない。場面数や句点の数も情報数にしない。
- 追加する事実は取得済みの一次資料から作り、既存のsanity_materialsへ渡す。今季成績、直近の流れ、同じ大会の順位、公式な次戦予定、対戦成績、節目など。別の日の資料・別大会の順位・所属クラブの成績を本人の成績として使わない。
- 材料不足・28秒未満・上限超過は `short_content_gate.json` に理由を残し、描画を停止する。言い換えや長い間で延ばさず、その回を見送るか、別の回とまとめて新たに点検する。
- 削除・短縮後の最終区間で再計数する。完成したMP4と同名の `.short_content.json` がない動画、失敗後に残った旧動画、実尺が合わない動画は公開器でも止める。
- 引用の情報数は「その発言がある」という数。発言の内容が事実であることの証明にはしない。追加する成績・結果等は一次資料で点検する。
- 横長の週次・長編は対象外。短い回も札・口調（雨衣は敬語）・字サイズ・既存の上限と動きを引き継ぐ。

実装の入口は `scripts/short_content.py`。PSの1組だけの回の補足は `scripts/short_context.py` で、同じ公式日程の終了試合から前戦の最終結果を加える。終了時刻や得点が不明なら加えない。得点ショートも既存の試合経過・本人の出場と詳細成績の構成を使う。

対応していない形や、情報の出典が材料に残っていない回は合格を推測しない。新しい形を足す場合は、実際に表示する材料の欄と重複のまとめ方を検査に追加し、保存材料の回帰試験を入れる。
