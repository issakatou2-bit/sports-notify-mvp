2026-10-22追加。実装・試験の根拠は架空のAPI応答であり、実API・CI・公開結果は未確認。

## ワールドシリーズ

`scripts/ws_topics.py` は既存の球団史・日程に次の話題を足す。

| key | 内容 |
|---|---|
| ws_ps_home_runs / ws_ps_rbi | 両球団それぞれの今季PS本塁打・打点上位 |
| ws_ps_average | 打率上位。既定20打席以上・打数1以上 |
| ws_ps_strikeouts / ws_ps_era | 奪三振・防御率上位。防御率は既定5回以上 |
| ws_ps_hits_streak / ws_ps_hr_streak | 今季PSで継続中の2試合以上の連続安打・本塁打 |
| ws_season_matchup | 今季レギュラーシーズンの直接対決の勝敗 |
| ws_japanese_players | 両球団の日本人選手の今季PS成績。打席・登板なしも明記 |

MLB Stats API `/schedule` の今季PS（F,D,L,W）の確定試合をgamePkで重複排除し、`/game/{gamePk}/boxscore` の選手成績を合算する。上位は各球団3人が既定で、境界の同順位を含む。打率・防御率の順位は丸め前の分数で比較し、表示時に丸める。投球回はアウト数で計算する。取得時刻は既存の出力の `updated_at`、対象シーズン・確定試合数・下限は各話題に付く。成績の取得失敗・欠測があれば、その成績からの話題は省略し警告する。

連続記録は選手自身の出場試合が対象。安打は四球・死球・守備妨害・犠打のみの試合を挟んでも継続し、その試合は数えない。犠飛のみの試合は安打の連続を切る。本塁打は打席があって本塁打0なら途切れる。過去シーズンの連続は含まない。

日本人選手は既存の `JP_PLAYERS_MLB` と今季PS出場者・公式active rosterを照合する。二刀流は打撃・投手の両成績を載せる。active roster取得時点の登録であり、WS登録メンバーの確定を意味しない。

下限・人数は `--min-pa 20 --min-ip 5.0 --top 3` で変更可能。投球回の末尾 `.1` / `.2` は1アウト / 2アウト。第1戦の日時は引き続き公式日程のUTCから日本時間へ変換する。本人指定の10/24 9時を試験で確認した。各話題は既存の key/hook/heading/intro/items/title と `ws: true` を持ち、既存の `next_asset` のws除外を利用する。

今回 `data/ws_topics.json` は実API未取得のため更新していない。

## コメント候補

`scripts/comment_seeds.py` は自チャンネルの公開トップレベルコメントをYouTube Data API `commentThreads` から日付順に読む。対象は直近7日・最大10ページ（100件/ページ）が既定で、`--days` / `--max-pages` で指定できる。返信は今回の取得範囲に含まれない。毎朝7:23 JSTの専用workflowを追加し、リポジトリ変数 `COLLESPO_COMMENT_SEEDS=on` で有効になる。未設定はジョブもスクリプトもオフ。

鍵は既存 `early_views.get` の `YOUTUBE_API_KEY` 環境変数経由、自チャンネルIDは既存値との一致を試験する。`isPublic` とチャンネルIDを確認し、候補の元動画を `videos.list` でも照合して、自チャンネルかつ `privacyStatus=public` の物だけ残す。

「初」「何年ぶり」「連続」「どっち」「なぜ」、疑問や訂正の表現を固定規則で拾う。要約は既存名簿・辞書にある選手名・球団名と、指標・問いの種類の定型語から組み立てる。本文の抜粋や自由文は保存せず、コメント主の名前・ID・URL・コメントIDも出力に持たない。元動画のURLを付け、同じ動画の同じ要約は件数にまとめる。固有の問いの細部は省略されるため、元動画のコメントを人が確認して採用を判断する。

`data/comment_seeds.json` には要約・検出規則・確認する公式API/資料・集計方法・裏付けの見込みを付ける。初・何年ぶりは過去全期間の確認、連続は定義の確認が必要。理由の問いは成績だけでは断定できないので、公式会見・発表・規則等の一次資料を要する候補とする。この段階では裏付けそのものは未検証。

既知の球団・選手・指標から野球かサッカーかを定型判定する。サッカーの候補は既存取得先のfootball-data.orgの試合結果・順位表や大会公式記録へ案内する。競技を特定できない候補は、元動画との照合後に公式資料を選ぶ必要があると明示する。

取得ページ数・走査件数・対象期間・ページ上限到達による不完全さも出力する。通信失敗や鍵未設定は空の候補と失敗状態で旧結果を置き換え、workflowを失敗扱いにして保存段へ渡す。初期JSONは `not_fetched`。候補抽出は既存の投稿処理に接続していない。AI判断は実装に含まれず、有料処理の設計追加も今回の対象外。
