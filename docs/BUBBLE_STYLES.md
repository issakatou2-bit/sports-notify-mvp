改行とページ送りは `caption_breaks.py` に集約。BudouXの日本語モデルを固定して同梱し、Pythonのテキスト解析部をApache-2.0で利用・適応した。出典は[公式リポジトリ](https://github.com/google/budoux)、モデル/原コードのGit blobは `scripts/vendor/budoux-NOTICE.txt`、全文ライセンスは同フォルダ。実行時にネットワークや外部の分かち書きサービスを使わない。

数字＋単位、投球回の分数、日付・時刻・スコア・打率、英単語、定型の「報道によると」を途中で割らない。ページは収まる範囲で句点→読点→文節の順。shortsの字幕/吹き出し/掛け合い、長編の新旧字幕とページ分割、YouTube用の日本語SRTに同じ規則を接続した。入り切らない文節は字を縮め、切捨てる代わりに明示的に失敗させる。

既定の画素一致を保つため、上記の改行は新型の指定時に適用する。従来型を含む全字幕に適用する場合は `COLLESPO_CAPTION_BREAKS=bunsetsu`。実行設定15本へ渡すが、今回リポジトリ変数は設定していない。

ガラスの縦じまは3px/秒、光は最大約3.5px/秒で漂う。模様は板の近くに限定。試作動画は保存材料・保存音声を使い、本番の描画関数を時刻ごとに実行して比較する。字幕の全ページ表示、全尺復号、各時刻のコントラスト4.5以上を検査。動きだけの検査では文・姿勢・背景の地を固定し、0/4/8秒の模様の変化を別に測る。

`COLLESPO_BUBBLE=slant` / `glass` のときだけ切り替える。未設定・空文字・未知の値は既存の描画を通す。変数自体は今回設定していない。
