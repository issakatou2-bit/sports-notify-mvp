## 第1期：進出争い（いま 〜 9/28）

### 材料は全部ある。実際に叩いて確かめた

`/standings` が1球団ごとに返すもの:

| 項目 | 中身 | いま持っているか |
|---|---|---|
| `magicNumber` | あと何勝（または相手の何敗）で決まるか | **持っていない** |
| `eliminationNumber` | あと何敗で消えるか。`E` は敗退確定 | **持っていない** |
| `clinched` / `divisionChamp` | 決定済みか | **持っていない** |
| `wildCardGamesBack` | ワイルドカード枠との差 | **持っていない** |
| `wildCardEliminationNumber` | WC争いからの敗退数 | **持っていない** |
| `runDifferential` | 得失点差 | 持っていない |
| `divisionRank` / `gamesBack` | 地区順位・ゲーム差 | 持っている |
| `streak` / `records.splitRecords` | 連勝・直近10試合 | 持っている |

**`Standing` に5項目足すだけ**で、9月の主題が丸ごと手に入る。

### なぜマジックナンバーが効くか

順位とゲーム差は「いまどこにいるか」しか言わない。
**マジックナンバーは「あと何回で終わるか」を言う。**
毎日1つずつ減っていく数字で、減った理由も明快
（自分が勝つか、相手が負けるか）。

しかも**日本の視聴者に説明が要る**概念で、
そこはこのチャンネルが得意な領域。用語集も資産動画もある。

## 第2期：ポストシーズン（9/29 〜）

### 既にある仕込み

`rule_postseason` が `gameType` を見て加点する。

```
F ワイルドカード   4点
D 地区シリーズ     5点
L リーグ優勝決定   6点
W ワールドシリーズ  8点
```

**王手の判定も入っている。** `seriesStatus` の勝敗を見て
「2勝1敗、勝った方が突破」と書ける。推測していない。

この部分は既に正しい。

### 壊れるもの

**10月に意味を失う仕組みが3つある。**

| 仕組み | 何が起きるか |
|---|---|
| 順位の視点 | 順位は確定済み。「地区2位」と言っても情報が無い |
| 連勝・直近10試合 | PSは最大7試合。10試合の記録が無い |
| 「明日の注目試合3つ」 | 1日1〜4試合しかない。3つ選ぶ意味が消える |

**「順位の視点」は私が今週入れたもの**で、9月までは効くが
10月には空振りする。競技を見分けたのと同じ形で、
**時期も見分ける必要がある**。

### いちばん重い問題

**最強の枠が痩せる。**

日本人選手の成績は視聴継続55.4%で、2位の1.8倍。
いま12人が9球団に散っている。

```
PSに残る球団   30球団中12
リーグ優勝決定  4球団
ワールドシリーズ 2球団
```

上の表から見ると、10月に残りそうなのは
**ドジャース・ホワイトソックス・カブス**の3球団前後、
**日本人選手は6人前後**。9月の半分になる。

そしてワールドシリーズの週は**2球団のみ**。
そこに日本人選手がいなければ、**最強の枠が1週間空く**。

### 手当ての案

**A. 枠の定義を広げる**
「その日出場した日本人選手」→「ポストシーズンに残っている日本人選手」。
出場が無い日は、そのシリーズでの通算成績を出す。

**B. 敗退した選手の今季総括へ切り替える**
ロッキーズの菅野智之はもう試合が無い。
だが**今季の成績は確定していて、語る材料としてはむしろ完成している**。
「今季を終えた日本人選手」という枠は、10月にだけ成立する。

**C. 空いた日は別の枠に譲る**
無理に出さない。7本を6本にする日があってよい。

**私の推しはBとC。** Aは「出ていない選手の話」を毎日することになり、
薄まる。Bは10月にしか作れない中身で、しかも**季節の区切りとして
視聴者の感覚にも合う**。

## 新しく作るもの

### 1. マジックナンバーの回（9月）

毎日1つずつ減る数字。順位表より動きがあって、説明も要る。

```
ずんだもん「マジック19って何なのだ？」
解説  「あと19回、ドジャースが勝つか相手が負けるかで地区優勝が決まる」
ずんだもん「昨日は20だったのだ」
解説  「昨日勝ったから1つ減った」
```

**既存の順位表の枠を置き換える形**にできる。
「現地の注目度」は既に畳んであるので、枠は増えない。

### 2. 進出決定・敗退の日（不定期）

`clinched` が立った日、`eliminationNumber` が `E` になった日。
**その日にしか出せない、明確な区切り。**

日本人選手の球団に起きたときだけ出す不定期枠なら、
本数を増やさずに済む。

### 3. 今季を終えた選手（10月）

敗退した球団の日本人選手の、今季の総括。
`morning_player`（今日の1人）の形式がそのまま使える。
