## 使い方と判断

`COLLESPO_MOTION=on` のときだけ `scripts/motion.py` を呼ぶ。未設定・off・未知の値は既存の描画と切り替えへ戻る。各描画器の接続はデコレーター、背景と切り替えと数字は共通関数の呼び出し。各workflowへ変数の受け渡しを追加しただけで、リポジトリ変数自体は変えていない。

一覧の文字・板は最初から2倍の画素で描画し、カメラの範囲を切り出して原寸へ縮める。字幕・見出し・出典・下隅の立ち絵は固定。全行を最初から読める濃さで置き、上から少しずつ上がる。寄っている行以外も読み続けられるよう、全行が安全域に収まる範囲へカメラを制限した。項目ID・描画時の文字の箱・カメラ変換後の箱を検査記録へ残す。

同じ項目への再描画では、別の入場や数字の光を繰り返さない。3本の主対象は概要の声で全項目を見せ、その後は既存の項目ごとの声と同じ項目IDへ寄る。音声を速めたり、読み上げ内容を変えたりしない。読み終わりに0.7秒の余白を確保し、その間に引く。

| `motion.SETTINGS` | 値 | 役割 |
|---|---:|---|
| overview | 0.8秒 | 共通一覧の最低の見渡し時間 |
| stagger / entrance / rise | 0.06秒 / 0.22秒 / 8px | 上から順に入場 |
| zoom_seconds / zoom | 0.35秒 / 最大1.20倍 | ease-in-out の寄りと引き |
| zoom_dense | 最大1.05倍 | 4件以上でも全文と立ち絵を両立 |
| dim | 16% | 読んでいない行を少し暗くする |
| pulse_seconds / pulse / light | 0.48秒 / 3.5% / 18% | 数字の小さい弾みと1回の光 |
| transition | 0.35秒 | 斜めワイプ・ガラスのぼかし |
| drift | 3px | 背景だけのゆっくりした移動量 |
| background_speed / drift_speed | 18% / 0.14・0.11rad毎秒 | 既存背景と追加移動の速度 |
| scale | 2 | 一覧の描画倍率 |

数字の対象は #152 の `fan_events.decision` と共用する。動きだけ有効なときも同じ事実から対象を選べるが、表情・効果音を有効化しない。数字を大きくした分の幅も予約する。既存背景の縦じま・照明はon時だけ18%の速さにし、#172のガラス内の背景は既存部品の動きを使う。

## 対応と同期の範囲

- Redditの反応：導入で3件の全体、コメントごとに当該項目へ寄る。高評価・返信数と取得元を残す。返信・注意書きは元の単独画面。
- 17時の勝利貢献：表紙・順位表・1〜3位の読み上げで同じ一覧を保持。本人の数字・順位・球団を残す。
- サッカー注目試合：表紙で3試合の一覧、各試合の声で当該試合へ寄る。ホーム・アウェー・日時・リーグを残す。
- 共通のランキング・全試合一覧・日本人一覧・コメント欄・順位表にも接続。8件までの一覧に対応し、それ以上は元のページ分割を維持する。1件ではカメラを寄せない。
- 共通のショート・長編の切り替え、MLB・サッカー・長編の背景、旧描画のフレーム使い回し解除へ接続。

3本は保存音声manifestの文・話者・kind・metaと原稿を完全照合し、WAV実測の開始・終了で寄る。字幕時刻と寄る項目の所有区間も全フレームで照合する。ほかの共通一覧は既存の行のat/endまたは字幕ページの時刻を使い、対応する項目が一意でない字幕では全体のままにする。既存字幕・#152数字強調は文字数比による時刻であり、音素の強制アラインメントを新設したとは扱わない。
