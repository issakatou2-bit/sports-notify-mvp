## 従来の工夫との対応

| 従来の制作で確認した工夫 | 今回の継承先 |
|---|---|
| generate_video.render_introの主題先行・対象日 | 冒頭に対象球団・明日9/30・全4試合。組み合わせ紹介は9/30開幕。番組名だけを大きくしない |
| render_gameのPICK番号・set_step | 各詳細カードの右上1/4〜4/4。実カード件数と順番を検査し、毎フレーム進む装飾バーを足さない |
| MLB_TEAM_COLOR・video_common.lift_color | 同じ球団色定義を色帯へ。暗い地色では明度を調整、球団名自体は明るい文字で読む |
| 日本人選手を球団の欄に出す | 題と所属の画面注記へ。所属を出場予定と断定しない |
| 先発と理由を必要な量だけ置く | 当該試合の公式probablePitcherだけ採用。情報が片側なら他方は確認中。初戦は勝ち上がり先、次戦は勝数・決着条件 |
| ease_out・情報の順次出現 | 描画済みの層を上から順に左から表示。静止画だけの切替に戻さない |
| video_common.crossfade / FADE_SECONDS | 同じ0.28秒の画面切替を使用。別の係数を増やさない |
| build_narration_track / SEGMENT_TAIL | 読み上げ＋既存0.7秒の間。音声と画面の区切りを揃える |
| キャラ・コレスポの前後呼称 | 発話speakerからキャラを選び下隅に胸上。めたん3黒T、ずんだもんCの服のみ黒T候補。承認済みの顔・肌・アルファを維持 |
| 公開台帳→実公開確認→Buffer/SNS | 既存経路を継続。見本完成や予約を、実公開・SNS投稿成功と扱わない |

旧レギュラー制作器、サイト、他の日次動画を一括置換しない。球場や天候・理由の大量表示は主題を押し出すため、自動で全部詰め込まない。口パク・全表情の置換は別の未完工程。

## 根拠と境界

公式資料: https://statsapi.mlb.com/api/v1/schedule および https://www.mlb.com/news/2026-mlb-playoff-and-world-series-schedule 。WCS第3戦は2連勝で終了したカードを除外し、残る試合数で開始時刻も変わるため、当日公式資料を再取得する。仮時刻を日本時間の確定日として公開しない。

DS/LCS/WSは勝ち上がりの表示と必要勝数を回戦に対応させる。休養/移動日・終了後・前年混入・勝者不整合・資料期限切れを既存の厳格な検査に通す。今後全日程の実運用成功を保証するものではない。

検証: 新構成15ケース、既存編集16ケース・シリーズ56ケースは手元で成功。Linux全検査、完成音声付き見本、実公開の結果は共有PS_ROLLOUT_2026-09-28.mdへ別段階で残す。描画効率化は従来の部品再利用を継続し、今回未測定の総時間削減率を主張しない。
