# TheSportsDB のスコア照合

確認日: 2026-10-14。main `09b1ea3e` からの隔離枝。対象は欧州サッカー結果の取得後の**内部の答え合わせ**。

`COLLESPO_THESPORTSDB_CHECK=on` の場合だけ `soccer_results.yml` に追加した段で実行する。未設定は段自体を実行しない。単独実行も未設定なら読み取り・通信・ファイル作成をせず終了する。既存の材料・スコア・原稿・動画・公開判定は変更しない。

## 無料の範囲と制限

[公式API文書](https://api.thesportsdb.com/documentation)で、V1無料キー123、無料30リクエスト/分、日別の返却上限3試合を確認。V2/ライブスコアは使わない。今回の実装はリーグとUTC開始日ごとに1回、呼出し間隔2.1秒以上、1起動10回まで、1時間キャッシュ。429ならその起動では後続通信をやめ、再試行しない。他用途で同APIを使う場合は共有の回数も考慮する。

[利用規約](https://www.thesportsdb.com/docs_terms_of_use.php)（2026-09-17版）は無料の開発用途を認め、アプリストアへの公開には有料加入を求める。本機能は内部の結果照合だけで、無料APIの画像・ロゴ・人名データを動画やサイトへ転載しない。申込・登録・有料キーの取得は行っていない。照合記録・要約には出典リンクを残す。将来ストア向けアプリへ搭載する場合は無料の開発用途の許可を流用しない。

## 判定と通知

- UTCの**開始日**＋リーグID＋ホーム/アウェーの両クラブで同一試合を絞る。結果のJST版の日付を開始日と混同しない。
- 表記揺れは固定の別名だけ。女子・ユース・リザーブを曖昧検索で取り違えない。重複候補は `ambiguous`。
- 終了状態と両スコアの数値が確認できた試合だけを照合。未掲載 `not_found`、未終了/スコア欠測 `not_final`、API失敗、回数上限は一致/不一致とは別に残す。
- 食い違いは `mismatch` と両スコアを記録し、GitHub Actionsの warning と Step Summaryで知らせる。既存の結果を訂正・除外せず、動画を止めない。メール・SNS・外部通知は送らない。
- `build/soccer_results/thesportsdb-check.json` と同じフォルダのcacheを既存のartifact保存で残す。公開の `data/soccer_results.json` へ二次スコアを混ぜない。
