# 球場・球団まとめの制作停止

2026-10-26の本人判断により、資産動画の `venue`、`season_team`、旧 `team` を新規の題材選択から外す。根拠は本人指定の棚卸し `inventory_20261025.md` 第3章。本数は増やさず、候補がなければ見送る。

停止条件は `scripts/asset_policy.py` に集約し、通常の自動選択、シーズンまとめ、明示指定の制作入口、音声のため録りへ適用する。生成コード・材料は保持し、再開時は `PAUSED_KINDS` を変更する。公開済み動画、再生リスト、過去の分析分類は変更しない。

健康診断は、停止種を除いた制作候補がない場合を不足としない。watchdog / missing_kinds の定時必須枠には元からこの種類がない。朝の報告・サイト説明・運用一覧にも停止と補充なしを明記する。

既存予約・在庫の取消は行わない。未公開の題・IDを含む一覧は `build/stop-venue-team-inventory.md` に保存し、コミットしない。接続できないリモートの予約・完成動画・音声キューは未確認として記録する。
