# 決めたことと、その反映先

決定を1か所に集め、**どの媒体まで反映したか**を残す台帳。

なぜ要るか。同じことを動画・サイト・説明文・用語集の4か所に別々に書いて
いるため、1か所だけ直すと静かに食い違う。実際に起きた例:

- 資産動画を3本足したとき、`ASSET_META` への登録を忘れた（既定のタイトルで
  投稿される一歩手前）
- 用語集の指標説明と、資産動画の同じ用語の説明が別々に書かれている
- 朝の動画の日付が米国日付、他は全部JSTだった

`python3 scripts/inventory.py --check` が、資産動画については登録漏れを
機械的に検出する。文章の食い違いは検出できないので、この台帳で追う。

## 変更の重さと、進め方

**取り返しがつくかどうか**で分ける。

### 軽い（そのまま進めてよい）

コード内の重み・文言・レイアウト・新規ページの追加。
間違えても次の実行で直る。

### 重い（必ず事前に合意する）

- 公開済み動画の削除・非公開化
- 既存URLの変更や削除（検索の評価が消える）
- チャンネル名・ブランド名の変更
- 配信時刻の変更（習慣が付いている場合）
- 外部サービスへの申請内容の変更（審査中のものを含む）
- ドメインやDNSの設定

これらは**明確な理由と、双方の理解がある場合にのみ**行う。
「たぶんこの方がいい」では動かさない。

### やらない

- 合意なく公開済みのものを消す
- 検証できていないことを、検証済みのように出す
- 数字を良く見せるために計算方法を変える

## 決定の記録

新しい決定はここに追記する。書式は
**決めたこと / 理由 / 反映先 / 状態**。

### 2026-08-12 勝利貢献スコアを導入し、計算方法を公開する

- **決めたこと**: 日本人選手の1日を0〜上限なしで採点し、順位をつける。
  投手と打者を同じ物差しに載せる。計算方法は全部公開する。
- **理由**: 成績を並べるだけでは「誰がその日いちばん効いたのか」が伝わらない。
  独自の点数を出す以上、再現できる形で公開しないと、
  都合よく決めた数字と区別がつかない。
- **反映先**: `morning_recap.py`（計算）/ `clutch.py`（場面の加点）/
  `score.html`（自動生成）/ 動画の画面と読み上げ / 動画タイトル
- **状態**: 反映済み。用語集への追記は未

### 2026-08-12 指標名を「勝利貢献スコア」にする

- **決めたこと**: 「コレスポpt」のような内輪の呼び方を使わない。
- **理由**: 初見の人に何の点数か伝わらず、内輪の遊びに見える。
- **反映先**: 動画タイトル / 読み上げ / 画面 / `score.html`
- **状態**: 反映済み

### 2026-08-12 日付は日本時間で表示する

- **決めたこと**: 米国日付ではなく、日本の視聴者が試合を見た日で表示する。
- **理由**: 米国日付Dの試合は日本時間D+1の朝。夜に「8月10日の成績」と出すと
  1日古く見える。他は全部JST基準だった。
- **反映先**: `morning_recap.py` の `date_jst` / タイトル / 画面 /
  サムネイル / ポッドキャストの題名
- **状態**: 反映済み

### 2026-08-12 MLBとサッカーを1つのチャンネルで続ける

- **決めたこと**: 分割しない。題材はタイトルの接頭辞と再生リストで示す。
- **理由**: MLBは3月下旬〜11月上旬、欧州サッカーは8月中旬〜5月下旬で、
  合わせると365日埋まる。分けると片方が年139日沈黙する。
  シミュレーションでも規模が大きいほど1チャンネルが有利
  （`scripts/channel_split_sim.py`）。
- **反映先**: 運用方針。再生リストは未作成
- **状態**: 決定のみ。再生リストの作成と自動振り分けが未

### 2026-08-12 冒頭は具体的な事実から入る

- **決めたこと**: 名乗りや日付から始めず、その日いちばん具体的な事実、
  または視聴者が検索した問いから始める。
- **理由**: 直近28日でショートの40.6%が途中でスワイプされている。
  冒頭の1文を変えたときに視聴維持率が15.5%→102.7%まで動いた実績がある。
- **反映先**: 日次ショート / 朝の2本 / 資産動画21トピック
- **状態**: 反映済み。`mlb_abbr` / `mlb_venue` / `mlb_rivalry` の3本は
  別のコードパスのため未

### 2026-08-12 検証できないものは別の枠で出す

- **決めたこと**: 翻訳した現地の反応は、数字のコーナーと混ぜない。
  画面の背景色を変え、動画も分ける。
- **理由**: 数字は誰でも同じものを確認できるが、和訳は確認できない。
  混ぜると、どこまでが確かめられる話なのか区別がつかなくなる。
- **反映先**: `generate_morning_short.py` の `VOICE_BG` / 動画の分割
- **状態**: 反映済み
