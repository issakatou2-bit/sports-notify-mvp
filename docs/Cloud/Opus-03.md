# Opus-03: 欧州サッカー「今日いちばん見られたハイライト」の回の材料づくりのコード下書き

作成: 2026-10-05 コレスポのPCのClaude（エマ）。別アカウントのリポジトリ（作業一覧つき）で、Opus 5.5 に頼む作業。

## 前提
- コレスポのコードは公開リポジトリ https://github.com/issakatou2-bit/sports-notify-mvp （ブランチ `main`）。**読むだけ。**取れなければ作業一覧を「保留」にして理由を書く。
- 成果物は作業をしているリポジトリの `collespo/` に、PRで出す。**外部のAPI（YouTube・football-data.org）は呼ばない。**検査は固定の材料（下で作る見本のJSON）で。秘密は書かない。

## 背景
本人（10/4）「五大リーグの方もちゃんとやっていきたい。今日いちばん盛り上がったハイライトとか」。設計は `docs/Cloud/out/08_soccer_formats.md` の (c)。入口の `scripts/soccer_buzz.py`（各大会の公式YouTubeのハイライトを集める道具。動画は作らない）がある。MLBの「現地の声」（`scripts/local_voices.py`）が、ハイライトのコメントを訳して回にしている仕組みの手本。

## 読むもの
1. `docs/Cloud/out/08_soccer_formats.md`（とくに (c) と「3. 直すか新しく作るか」）
2. `scripts/soccer_buzz.py`（何を取ってどんな形で残すか）
3. `scripts/local_voices.py`（コメントの取り方・訳し方・出典の残し方・選び方）
4. `notability_engine.py` の `JP_PLAYERS_SOCCER`（日本人選手の名簿）
5. `scripts/generate_morning_short.py` の `soccer_race`・`soccer_week` の作り方（材料からショートを作る既存の型）

## 作るもの（`collespo/`）
1. `collespo/soccer_highlight.py`: `soccer_buzz` の形の材料から、その日の1本を選び、ショートの材料（題・冒頭・項目・出典）を作る関数。
   - 選び方: 24時間以内に公開された公式ハイライト。**日本人選手の試合を先に**（名前・クラブで判定）、その中では再生数の多い順。日本人選手の試合が無ければ再生数の多い順。
   - 中身: 試合（大会・節・スコア）、再生数（いつ時点か）、コメント欄から1〜2件（原文と訳の両方、訳は呼び出し側が渡す形にして、この関数ではAIを呼ばない）、日本人選手の出場・得点（材料にあれば。無ければ言わない）。
   - 題: 「【欧州サッカー】三笘薫のブライトン対〇〇｜ハイライト再生数1位」のように、内容をそのまま。読点で区切るキャッチコピーを使わない。
   - 出さない日: 材料が無い・24時間以内のハイライトが無い・同じ試合を出した（状態ファイルで覚える案）。
2. `collespo/test_soccer_highlight.py` と見本の材料 `collespo/fixtures/soccer_buzz_sample.json`（**作り話の選手・試合を本物のように書かない**。架空なら「架空」と分かる名前にする）。
3. `collespo/README_soccer_highlight.md`: ワークフローへのつなぎ方の案（いつ動くか・コメントの取り方・訳し方・既存の19:00/19:30の枠との関係）、決めてほしいこと。
