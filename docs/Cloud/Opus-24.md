# Opus-24: ストーブリーグ（11月〜2月）の企画と材料

作成: 2026-10-09 コレスポのPCのClaude（エマ）。

> **コレスポのコードとデータ**: 最新は公開リポジトリ `issakatou2-bit/sports-notify-mvp` の main（`https://github.com/issakatou2-bit/sports-notify-mvp/archive/refs/heads/main.tar.gz` を取って読む）。成果物はこのリポジトリの `collespo/` の下に作り、PRで出す。秘密は書かない。外部の有料APIは呼ばない（MLB Stats API など無料・鍵なしの公開APIは読むだけならよい）。本番のコードは直接変えない（取り込みはコレスポのPCのClaude）。
> **背景**: 2026-10-09 の分析ページ「コレスポの強みと伸ばし方」（要点: 再生の83%がShortsのおすすめ、登録者のフィードは2%。PSの試合の話題が最強（中央値233回）、毎日の17:00〜20:00枠は数十回。900〜1,000回で止まる回が多い。登録は約2,400回に1人。登録1,000人には「登録する理由」と1日の量が要る。11月からMLBの試合が無くなる）。

## 作るもの（`collespo/offseason/`）
- MLBの試合が無い11〜2月の柱の企画書: 日本人選手の移籍・FA・ポスティング（NPBからの挑戦）・契約・来季の展望・受賞（MVP・サイヤング・新人王・ゴールドグラブ）・殿堂入り投票。1日の本数と時刻の案、どの型が試合の話題の代わりになるか。
- 材料の取り方: MLB Stats API の `transactions`（取引）・`awards`、公式発表のRSSなど無料で取れるもの。取れる項目の見本（実際に1回読んだ結果の抜粋）。噂やまだ決まっていない話は扱わない決まり。
- 見本の台本3本（材料の写しから、数字は材料のものだけ）。
- 欧州サッカーとの組み合わせ（同じ日に両方出す場合の時刻）。
