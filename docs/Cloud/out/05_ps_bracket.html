画面使ったもの
1 トーナメント最新版 series の8つ（round が F＝ワイルドカードシリーズ4つ、D＝地区シリーズ4つ）。各 teams の name・wins・players、over・winner。地区シリーズの「10月4日に第1戦」は next.day・next.game。
どの地区シリーズの勝者どうしがLCSで当たるかは、teams の seed（1番シード対4・5番の勝者、2番シード対3・6番の勝者）から組んだ。リーグ優勝決定シリーズ・ワールドシリーズは材料に series が無いので「未定」。
略称と色は notability_engine.MLB_TEAM_ABBR・MLB_TEAM_COLOR。
2 初戦勝者の突破率 数字はすべて仮（--%・○）。突破率・母数・本拠地／敵地の割合・対象の期間は、PC側（Codex）の集計を入れる場所。棒の長さも決めていない（点線の枠だけ）。
下の「今年の地区シリーズ」の4つの組み合わせだけは材料どおり（series の D の teams）。第1戦の勝者は、材料の時点（10/3）でまだ試合が無いので「未定」。
3 LCSの組み合わせ 地区シリーズ4つの teams・wins・over・winner と players。
材料の時点ではどの地区シリーズも0勝0敗で、「今リードしている球団」が無い。そのため初めの表示は「考えられる組み合わせ4通り」。画面の下のボタンで勝ち上がる球団を選ぶと、「〜なら」の1つの組み合わせの形になる（勝敗の数字は作っていない）。リードしている球団がいる版の材料なら、その球団を自動で選ぶ。
日本人選手どうしの対戦になる組み合わせ（ナ・リーグのドジャース対パドレス）には一言添えた。

勝ち上がり図の線の動かし方（提案）

  • 終わったシリーズの線から順に伸ばす: ワイルドカードシリーズの勝者 → 地区シリーズの枠（0.4秒ずつ）。負けた球団は線が伸びる前に薄くする。
  • 次に、今戦っている地区シリーズの枠だけを明るくし、勝敗の数字を一度だけ数え上げる（0→現在の勝数）。終わっていない枠から先（LCS・WS）の線は点線のまま動かさない。
  • 最後に日本人選手の名前を枠の中にふわっと出す（ア・リーグ → ナ・リーグの順）。線と名前を同時に動かさない（目が追い切れない。推測）。
