今の17:00（scripts/generate_morning_short.py の players の回）は、読み上げの区切りごとに次の順で画面を出している（build_narration と main の描き分けから読んだもの）。

数字の出どころ

  • 成績（打数・安打・本塁打・打点・四球・得点・投球回・自責・奪三振・被安打・与四球）、球団名、成績の1行、「先制打点」とその注記、前回の点数・直近の平均: data/recap_history/2026-09-29.json の値そのまま。
  • 「1回に犠牲フライで先制」: 同じファイルの村上宗隆の clutch_plays（event: Sac Fly, inning: 1, kind: 先制）。
  • スコア（村上宗隆63・松井裕樹58・鈴木誠也55）と並び順: 材料の数字から scripts/morning_recap.py の contribution で計算した値（今の17:00が画面に出しているのと同じ計算。並べ方は sort_players と同じ高い順）。「前回との差」はスコアと材料の prev_score の差。
  • 「ワイルドカードシリーズ」とア・リーグ／ナ・リーグ、対戦相手: data/postseason.json の series（ホワイトソックス対アストロズ、パドレス対カブス）。この日が第何戦かは材料で確かめていないので書いていない。

安全域の見方

  • 上8%の中に「コレスポ」「MLB / POSTSEASON」「1/3」を置いているのは今の ps_render_template.py と同じ扱い（看板・進み具合で、重要な文字ではない）。
