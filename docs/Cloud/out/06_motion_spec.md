## 読む順番

## まとめ

- 今の動きは「行が左から順に入る」「画面の頭の0.28秒の重ね合わせ」「読み上げ中の行の強調（PS予告だけ）」「背景の円弧のゆっくりした揺れ」が中心。**画面の中身が出そろったあとは、ほとんど動かない**。画面の切り替えも、どこでも同じ重ね合わせ。
- 足すのは8つ（下の表）。どれも「どこを読めばよいか」を示すためのもので、**入りきるまでの時間は今と同じ1.2秒以内**に収める。
- 型を増やしすぎないよう、**イージングは3つだけ**（減速・なめらか・小さな行き過ぎ）、**入場の向きは今の「左から」に統一**する。
- おすすめの入れる順: ①読み上げ中の行の強調を一覧・順位表にも広げる（今ある仕組みの延長で手間が小さい）②ページ送りと章の見出しカード（「移り変わりがない」に直接効く）③数字のカウントアップ。

## 使うイージング（3つだけ）

| 名前 | 式（p は 0〜1） | 使いどころ |
|---|---|---|
| 減速（ease_out） | 1 − (1 − p)³ | 入場・数字・棒・線。今の `video_common.ease_out` と同じ |
| なめらか（ease_in_out） | p² × (3 − 2p) | 強調の切り替え・ページ送り・ワイプ（始めも終わりもゆっくり） |
| 小さな行き過ぎ（ease_out_back） | 1 + 2.2×(p − 1)³ + 1.2×(p − 1)² | 立ち絵の反応と、順位表の自分の行が浮くときだけ（行き過ぎは最大で約5%） |

## 画面の型ごとの組み合わせ

時間は画面の頭からの秒。「入場」は今ある行の入場（左から56px・0.38秒・0.16秒ずつ）。

| 画面の型 | 動きの順番 |
|---|---|
| 表紙 | 0.0 重ね合わせ（今ある）→ 0.0〜 入場（日付の行 → 1位の名前 → 成績の行 → 記録の帯）→ 帯が入った瞬間に 8 うなずき（スコア130以上なら驚き）→ 名前の光（今ある、100点超えのみ）。数字のカウントアップは使わない（表紙はサムネイルになるので、止まった絵で読めることを優先） |
| 一覧（17:00の成績など） | 入場（行）＋ 各行のスコアに 1 カウントアップ（行の入場と同時）→ 1.2秒〜 2 強調（読み上げに合わせて行を移る）→ 次のページがあれば 5 ページ送り |
| 順位表（進出争い・ワイルドカード） | 入場（行）＋ 勝数に 1 カウントアップ → 入場が終わったら 7 自分の行が浮く → 読み上げが別の球団に移ったら、浮きを戻してから 2 強調 |
| 比較（突破率・2人の比較） | 見出しの入場 → 4 棒が伸びる（値は 1 で同時に）→ 2 強調で、読み上げている棒以外を沈める |
| 引用（番記者の投稿・現地の声） | 入場は**透明度だけ**（横に動かさない。言葉を読ませる画面なので位置を動かさない）0.4秒 → 出典の行 → そのまま止める。強調・カウントアップは使わない |
| 勝ち上がり図 | 枠の入場（左の列から）→ 6 線が伸びる（終わったシリーズから）→ 今戦っているシリーズの枠に 2 強調 → 日本人選手の名前を透明度だけで出す |
| 章の見出しカード | 3 ワイプ。前の画面の上を帯が覆い、帯が抜けた下に次の画面（次の画面の入場は帯が抜け始めてから） |
| 画面の切り替え | 同じ話題の続き＝5 ページ送り、話題が変わる＝今の重ね合わせ（0.28秒）、章が変わる＝3 ワイプ。**この3つ以外は使わない** |

## 読ませる時間を削らないための決まり

- 入りきるまで（全部の要素が出そろうまで）は**1.2秒以内**（今の `ENTRY_SECONDS` と同じ）。これを超えるときは、同じ段の要素を同時に入れる。
- 章の見出しカードは読み上げの章の名前と同時に出し、合計1.6秒を超えない。
- 動きが終わったら止める。止まったあとに動き続けてよいのは背景の揺れ（今ある）だけ。
- 安全域（上8%・下18%・右13%）の外へ動かさない。7 の右へのずれ（+12px）も右端 940px を超えない位置の行だけにする。

## 1コマずつ描く場合の書き方（PIL、疑似コード）

30コマ/秒、`t` はその画面の頭からの秒。今の `ps_motion_template.frame` と同じく、**動かす部品は先に1回だけ描いて切り出しておき**、毎コマは貼る位置と濃さだけを変える。

```python
def clamp(x): return max(0.0, min(1.0, x))
def ease_out(p): return 1 - (1 - p) ** 3                 # 今の video_common.ease_out
def ease_in_out(p): return p * p * (3 - 2 * p)
def ease_out_back(p): return 1 + 2.2 * (p - 1) ** 3 + 1.2 * (p - 1) ** 2

def progress(t, start, dur):
    return clamp((t - start) / dur)

# 入場（今あるもの。i 番目の行）
p = progress(t, 0.16 * i, 0.38); e = ease_out(p)
paste(row, x=x0 - 56 * (1 - e), y=y0, alpha=e)

# 1 数字のカウントアップ（行と同時に始める）
e = ease_out(progress(t, 0.16 * i, 0.6))
draw_text_right(right_x, y, str(round(target * e)))      # 右寄せで、桁が増えても右端は動かない

# 2 強調の切り替え（focus が変わった時刻を changed_at に持つ）
k = ease_in_out(progress(t, changed_at, 0.2))
a_new = DIM + (1 - DIM) * k          # 新しく読む行
a_old = 1 - (1 - DIM) * k            # さっきまで読んでいた行
bar_h = row_h * k                    # 縦線は上から伸びる

# 3 章の見出しカード（入り0.45・止まる hold・抜け0.3）
if t < 0.45:      x1, x2 = 0, 1080 * ease_in_out(t / 0.45)
elif t < 0.45 + hold: x1, x2 = 0, 1080
else:             x1, x2 = 1080 * ease_in_out(progress(t, 0.45 + hold, 0.3)), 1080
draw.rectangle((x1, 0, x2, 1920), fill=ACCENT)           # 帯の下は前の画面→次の画面に差し替える
title_alpha = clamp((x2 - 540) / 300) if t < 0.45 + hold else 1 - progress(t, 0.45 + hold, 0.15)

# 4 棒が伸びる（j 本目）
e = ease_out(progress(t, 0.12 * j, 0.6))
draw.rounded_rectangle((x0, y, x0 + max_w * value / max_value * e, y + 56), radius=10, fill=COLOR)

# 5 ページ送り（前のページの最後のコマ prev と、次のページ cur）
k = ease_in_out(progress(t, 0, 0.3))
out = background(); paste(prev, x=-120 * k, alpha=1 - k); paste(cur, x=120 * (1 - k), alpha=k)

# 6 線が伸びる（折れ線 pts、n 本目は 0.35 秒ずつ遅れる）
e = ease_out(progress(t, 0.35 * n, 0.35))
draw_polyline_partial(draw, pts, length=total_length(pts) * e)   # 区間を順にたどって途中で止める

# 7 自分の行が浮く（入場が終わった ENTRY_SECONDS から）
k = ease_out_back(progress(t, ENTRY_SECONDS, 0.3))
paste(row_shadow, x=x0 + 12 * k + 6, y=y0 + 6, alpha=0.5 * clamp(k))
paste(row, x=x0 + 12 * k, y=y0)
draw.rounded_rectangle(row_box_shifted, outline=ACCENT, width=round(4 * clamp(k)))

# 8 立ち絵の反応（記録の帯が入った時刻 at）
p = progress(t, at, 0.36)
dy = 6 * math.sin(math.pi * p)                           # うなずき
s = 1 + 0.05 * math.sin(math.pi * progress(t, at, 0.3))  # 驚き（中心を固定して縮尺）
paste(sprite.resize(scaled(s)), x=x_center - w * s / 2, y=bottom - h * s + dy)
```

- 毎コマ `resize` すると重いので、8 の驚きは縮尺の違う版を3〜4枚だけ先に作って選ぶ（推測: 0.3秒＝9コマなので、見た目の差はほとんど出ない）。
- 1 のカウントアップは文字を毎コマ描くことになるが、数字の部分だけを描き、行の残りは切り出した版を貼る。
