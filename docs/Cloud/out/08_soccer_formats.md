# Cloud-08: 5大リーグのショート3つの型（情勢・明日の注目・今日のハイライト）

作成: 2026-10-04 クラウドのClaude（指示書 `docs/Cloud/Cloud-08.md`）。画面の見本は `docs/Cloud/out/08_soccer_formats.html`。

本人（10/4）「五大リーグの方もちゃんとやっていきたい。今のシーズン情勢とか、明日の注目試合はもちろん、今日いちばん盛り上がったハイライトとか」。

## 読む順番

1. **「まとめ」**（すぐ下）
2. **「2. 3つの型の設計」**
3. **「3. 直すか新しく作るか」**
4. 「1. 今の枠の棚卸し」は根拠として。最後に「気づいたこと」

## まとめ

- 今あるサッカーの枠は、毎日の「明日の注目試合」（19:30公開）、節が終わった大会の「順位争い」（20:30公開）、試合が無い日の「日本人選手の週末」（19:30公開）の3つ。どれも19時のMLBの回が終わったのを合図に動く。ほかに道具が2つ（ハイライトの試し取り・名簿の確認）。
- (a) シーズン情勢は **今の「順位争い」を直す**（材料も仕組みもある。降格圏と上位の線を足し、日本人選手のクラブを表紙に）。
- (b) 明日の注目試合は **今の「欧州サッカー」の回を直す**（選び方はある。題と画面を「日本人選手の試合を先に」「1試合1画面」に寄せる）。
- (c) 今日いちばん見られたハイライトは **新しく作る**。入口の `scripts/soccer_buzz.py` はあるが、まだ動画を作らない道具のまま。MLBの「現地の声」と同じ仕組みが使える。

## 2. 3つの型の設計

### (a) シーズン情勢（リーグごと）

| 項目 | 決め |
|---|---|
| 中身 | 表紙: 大会名・節、**日本人選手のクラブの順位と線までの勝点**（今の `soccer_race.json` の `jp` の `lines` の文）。中身: 順位表の上位（首位〜EL圏の線のすぐ下まで）と下位（日本人選手のいるクラブ〜最下位）、CL圏・EL圏・降格圏の線 |
| 選び方 | 今の `--due` のまま（節が全クラブ終わった大会。日本人選手がいる大会が先）。1本1大会 |
| 尺の目安 | 30〜40秒（今の形と同じ。表紙1枚＋順位表1〜2枚） |
| 題 | 「【欧州サッカー】プレミアリーグ第5節終了｜三笘薫のブライトン3位」のように、大会・節・日本人選手のクラブの位置をそのまま。キャッチコピーを付けない |
| 出さない日 | 今と同じ（節の途中・最低節数未満・もう出した）。代表戦期間は節が進まないので自然に出ない |
| 足すもの | **降格圏の線**（今の `lines` は CL圏・EL圏だけで、残留争いが言えない）。リーグごとの降格の枠数は材料が要る（推測: 大会ごとの定数で足りる） |

### (b) 明日の注目試合

| 項目 | 決め |
|---|---|
| 中身 | 表紙: 日付（日本時間）と、試合を時刻順に最大3つ（キックオフ・対戦・日本人選手）。中身: 1試合1画面（大会と節、対戦、日本人選手、国内リーグの順位、選んだ理由） |
| 選び方 | **日本人選手のいる試合を先に**、その中では日本人選手が出られる状態（`soccer_availability.py` で離脱中でない）を先に。日本人選手の試合が無い日は、今の `notability_engine` の点数（昨季の順位どうしなど）で上から。キックオフまで45分を切る試合は外す（今の決まり） |
| 尺の目安 | 試合1つにつき10〜12秒、表紙6秒。3試合で40秒前後 |
| 題 | 「【欧州サッカー】10月22日の注目試合｜伊藤洋輝のバイエルン対アーセナル ほか」。日本人選手の名前を先頭に（今の題の作り方と同じ考え方） |
| 出さない日 | 注目試合が0件の日（今と同じ）。その日は (a) か「日本人選手の週末」に任せる |
| 見本で気をつけたこと | 「選んだ理由」は材料の `reasons` をそのまま出し、言葉を足さない。見本のCLの `highlights` にある「昨季2位と1位」は、どの大会の順位か材料から読み取れなかったので使っていない |

### (c) 今日いちばん見られたハイライト（新しく作る）

| 項目 | 決め |
|---|---|
| 中身 | 表紙: いちばん見られたハイライトの試合（大会・節・対戦・スコア）と24時間の再生数。中身: その動画のコメント欄で支持の多いコメント2〜3件（訳＋原文＋いいね数）。日本人選手がいれば名前 |
| 選び方（PC側が実装） | 各大会の公式YouTubeチャンネルの、直近24時間に公開されたハイライト（`soccer_buzz.py` の入口）を再生数の多い順に。日本人選手のいるクラブの試合は先に見る（`soccer_buzz.py` の説明では、題に日本人選手の名前があると再生が2.8倍）。ただし再生数の差が大きいときは数字の多い方を取る（「いちばん見られた」と言う以上、順番を作り変えない） |
| コメントの扱い | MLBの「現地の声」（`scripts/local_voices.py`）と同じ: 原文を併記・「翻訳」と明記・出典（どの公式チャンネルのどの動画か）。訳で盛らない |
| 尺の目安 | 30秒前後（表紙8秒、コメント2〜3件で各7秒） |
| 題 | 「【欧州サッカー】今日いちばん見られたハイライト｜バイエルン対アーセナル」のように対戦をそのまま（見本の題の例の対戦は (b) の材料の試合を使っただけで、再生数は無い） |
| 出さない日 | 24時間にハイライトが1本も無い日（代表戦期間・オフ）、コメントが2件に満たない日（MLBの「コメント欄」の回と同じ考え方）。再生数が取れなかった日 |

## 3. 直すか新しく作るか

| 型 | 直す／新しく作る | 理由 |
|---|---|---|
| (a) シーズン情勢 | **今の「順位争い」（`soccer_race`）を直す** | 選ぶ仕組み（節の終わり・最低節数・二度出さない）と日本人選手の線の文がもうある。足りないのは降格圏の線と、上位・下位の見せ方だけ |
| (b) 明日の注目試合 | **今の「欧州サッカー」の回（`soccer_daily`）を直す** | 試合の取得・注目度・離脱中の判定はもうある。直すのは並べ方（日本人選手の試合を先に）と画面（1試合1画面） |
| (c) 今日のハイライト | **新しく作る** | 今は道具（`soccer_buzz.yml`）が手動で動くだけで、動画を作る段が無い。MLBの「現地の声」の作り方を、大会ごとのチャンネルに広げる形になる |

## 4. 画面の見本について

`08_soccer_formats.html` に (a)(b)(c) を2枚ずつ（計6枚）。

- (a) は `data/soccer_race.json`（9/24、プレミアリーグ第5節終了）と `data/soccer_preview.json` の順位表（10/3生成、同じ第5節の並び）。
- (b) は `data/soccer_games.json` が**9/30〜10/3の4回ともどれも0試合**だったため、`soccer_preview.json` にあるチャンピオンズリーグ第3節の日程（10月22日 日本時間 1:45・4:00）を使った。「明日」は見本の言い方。
- (c) は材料が無いので、再生数・コメント・試合はすべて仮（○や「（…）」）。

## 気づいたこと

- **プレミアリーグの順位表に、名簿で「ELC（2部）」になっている日本人選手のクラブが入っている。**`soccer_preview.json` のプレミアリーグの順位表にハル・シティ（8位）・イプスウィッチ（11位）・コベントリー（18位）があり、`jp_players_for_club` ではそれぞれ守田英正・前田大然・坂元達裕が返るが、リーグは「ELC」。`soccer_race.json` のプレミアリーグの日本人選手（6人）にこの3人は入っていない。名簿のリーグが古いままの可能性がある（推測）。名簿の確認（`check_soccer_roster.yml`）で見てほしい。
- `soccer_daily.yml` の説明には公開「19:00」「20時」の話が残っているが、実際の公開の指定は `--publish-at "19:30"`。
- `data/soccer_games.json` が9/30〜10/3の4回続けて0試合。週末（10/3）も0なのは代表戦期間でなければ気になる（理由は材料に無い）。
