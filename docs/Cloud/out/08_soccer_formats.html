画面使ったもの
a-1soccer_race.json の PL（round: 5・round_complete: true）の jp（名前・クラブ・順位・勝点・lines の text・out・out_note）。三笘薫の「負傷で離脱中（復帰見込み10月10日）」は out_note「Hamstring injury - Expected back 10 Oct」を訳したもの。高井幸大は lines が空なので、線の文は出していない。
a-2soccer_preview.json の PL の table（10/3生成、各クラブ5試合。soccer_race.json の第5節終了と同じ並び）。上位1〜6位と下位15〜20位（7〜14位は省略）。「CL圏内」「EL圏内」の線の位置（4位と5位の下）は soccer_race.json の lines の at。降格圏の線は材料に無いので引いていない（lines は CL圏・EL圏だけ）。日本人選手は jp_players_for_club（PLの選手だけ）。
b-1・b-2soccer_preview.json の CL の early（第3節、2026-10-21 16:45 UTC のリール対ガラタサライ、19:00 UTC のバイエルン対アーセナル）を日本時間にした（10月22日 1:45・4:00）。日本人選手は jp_players_for_club、選んだ理由の「伊藤洋輝の所属クラブ」は CL の highlights の reasons。リーグの順位は同じファイルの table（バイエルン ブンデスリーガ2位・4試合、アーセナル プレミアリーグ2位・5試合、リール リーグ・アン4位・5試合）。「明日」は見本の言い方で、材料の日付（10/3）から見た明日ではない。
c-1・c-2材料が無いので仮。再生数・コメント・いいね数・試合は○や「（…）」で示した。取り方はPC側（各リーグ公式YouTubeの24時間の再生数とコメント欄。scripts/soccer_buzz.py が入口）。
