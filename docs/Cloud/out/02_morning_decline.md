## まとめ

**落ち込みは2段ある。**公開7日目の再生の中央値で、8/18〜8/28 が **916**、8/29〜9/13 が **162**、9/14〜9/26 が **58.5**。

- **1段目（8月末→9月初め、916→162）は、チャンネル全体の減りと同じ時期。**チャンネル全体の1日の再生（流入の合計）の中央値は 2,312 → 769.5 で、18:00・19:00の回も同じように減った。17:00だけの問題ではない。
- **2段目（9/14以降、162→58.5）は17:00の回の側の問題と見られる。**同じ時期、チャンネル全体は 769.5 → 706 でほぼ横ばい。18:00の報道（51→54）・19:00の予告（106→92）も横ばいだった。
- 2段目の時期と合う変化が、材料に2つあった。どちらが効いたのかは、材料だけでは切り分けられない。
  1. **9/16から「ファンのコメント欄」の回が18:00から17:30に移った。**17:00の回は30分あとに次の回が来るようになり、17:30の回自体も同じ時期に中央値 51 → 18 に減った。
  2. **9/7から動画が長くなった**（推定の長さの中央値: 8/18〜8/28 は35秒、9/14〜9/26 は75秒）。平均視聴秒はほぼ同じ（26秒 → 21秒）なので、**平均視聴率が 69% → 28.5% に下がった**。ただし長くなったのは9/7からで、9/7〜9/13 の7本は中央値147とまだ高かった。時期は1週間ずれる。
- 題の形（毎日同じ）・曜日・出場人数は、2段目の段差を説明しない（下の各項）。
- **推測**: 2段目は「17:30の回の追加」と「長さ・視聴率」のどちらか、または両方。材料の範囲では因果は言い切れない。

### 試す価値のある変更（3つまで）

1. **17:30の回を18:00以降に戻す（17:00と1時間以上あける）。**1〜2週間続けて、17:00の公開7日目の再生を9/16〜9/26（中央値55.5、10本）と比べる。いちばん小さい変更で、2つの仮説のうち片方だけを動かせる。
2. **17:00の長さを9月初めの水準（40秒前後）に戻す。**1と同時に動かすと、どちらが効いたか分からなくなるので、1のあとに試す。どの画面で長くなったかは材料に無い（**推測**: 7日間の合計・節目・現地の声など、あとから足した画面）。
3. **題の名前を「スコアの高い順」にし、本塁打の選手を落とさない。**今の題は、材料のファイルの並び順で先頭3人を取っている（下の「追加2」）。題の形の案（実例。数字は `data/recap_history/` の値そのまま）:

   - 9/14の実際の題: 「【MLB】松井裕樹・ヌートバー・岡本和真 ほか｜9月14日 日本人選手 勝利貢献スコア ランキング」

## 計算のしかた

- **再生は「公開7日目」の値で比べる。**`data/analytics.json` の `days` は1日ごとの集計で、それぞれ**直近28日間**の再生の**上位200本**だけを持つ（10/3の集計は 9/5〜10/3）。そのため最新の集計だけで比べると、9/4以前の回は期間の外になり、再生の少ない回は上位200本から落ちる。
  - そこで、各回について**公開日＋7日の日の集計**の値を使った（その日の集計が無いときは、次にある日。表に何日目かを書いた）。7日目と14日目の値はほとんど同じで（例: 9/13 は 442 と 443）、再生は7日でほぼ止まる。
  - その日の集計の上位200本に入っていない回は「○未満」（その日の200位の再生数）と書いた。中央値の計算では0として数えた（9/6 の1本だけ）。
- **平均視聴率・平均視聴秒**も同じ日の集計の値（`averageViewPercentage`・`averageViewDuration`）。
- **推定の長さ**＝平均視聴秒 ÷ 平均視聴率。動画の長さそのものは材料に無いので、この割り算で出した。
- **公開日**は `data/published_videos.json` の `morning` の `publish_at`（無ければ `published_at`）を日本時間にした日。
- **区切り**: A＝8/18〜8/28（11本）、B＝8/29〜9/13（16本）、C＝9/14〜9/26（12本）。9/27以降は公開7日目に届いていないので比べていない。
- **中央値**を使った（平均だと 9/14 の491のような1本に引っぱられる）。本数が少ないところは「傾向」として書いた。

## 仮説ごとの確かめた結果

### 1. 題の形が毎日同じ → **2段目の原因としては支持しない**

- 題は8/17から「【MLB】A・B・C ほか｜M月D日 日本人選手 勝利貢献スコア ランキング」で、9/29まで形は変わっていない（9/30・10/1は人数が3人以下で「ほか」が無い）。
- **同じ形のまま、8/18〜8/28 は中央値916だった。**形が同じことだけでは、9/14の段差は説明できない。
- 「毎日同じ形なので押されにくくなった（慣れ）」かどうかは、表示回数とクリック率が材料に無いため**分からない**。

### 2. 題の先頭の選手（大谷翔平・山本由伸の有無） → **8月は差が大きい。9月は本数が少なく分からない**

| 区切り | 大谷翔平か山本由伸が題にある | 無い |
|---|---|---|
| A 8/18〜8/28 | 6本・中央値931 | 5本・中央値434 |
| B 8/29〜9/13 | 4本・中央値260 | 12本・中央値148.5 |
| C 9/14〜9/26 | 3本・中央値53 | 9本・中央値59 |

- 8月は、2人のどちらかが題にある回が高い傾向。9月はどちらも3〜4本しかなく、差は言えない。
- 大谷翔平が題に入った本数は A 11本中5本、B 16本中2本、C 12本中2本。B と C で割合はほぼ同じなので、**2段目の段差はこれでは説明できない**。
- 題の先頭（1人目）が大谷翔平だったのは 8/16（74）と 8/19（904）の2本だけで、比べられない。

### 3. 冒頭2秒の離脱（`curve` の最初の点） → **材料では分からない**

- `curve` があるのは、各日の集計のうち一部の動画だけで、17:00の回では **49本中9本**。C の期間（9/14〜9/26）は **9/14の1本だけ**（最初の点1.077、2秒の点1.077、5秒の点1.013）。比べられない。
- そもそも `curve` は「見始めた人のうち、その位置を見ている割合」で、**フィードで流されて見始めなかった人（スワイプされた割合）は入っていない**。冒頭での離脱を確かめるには、YouTube Studio の「視聴した／スワイプした」の数字が要る（クラウドでは見られない）。

### 4. 同じ日のほかの回との食い合い → **時期は合う（傾向）。因果は分からない**

公開7日目の再生の中央値:

| 回 | 公開時刻（日本時間） | A 8/18〜8/28 | B 8/29〜9/13 | C 9/14〜9/26 |
|---|---|---|---|---|
| 17:00 成績（`morning`） | 17:00 | 916 | 162 | 58.5 |
| 17:30 ファンのコメント欄（`morning_voices`） | **9/15まで18:00、9/16から17:30** | 115 | 51 | 18 |
| 18:00 報道（`morning_press`） | 18:00 | 210 | 51 | 54 |
| 19:00 予告（`daily`） | 19:00 | 313 | 106 | 92 |
| 20:00 ポストシーズン（`morning_postseason`） | 20:00 | ― | 38 | 37 |

- B → C で減ったのは、17:00 と 17:30（9/16から）の2つだけ。18:00・19:00・20:00 は横ばい。
- 17:00 の回を9/16の前後で分けると、9/5〜9/15 の11本は中央値147、9/16〜9/26 の10本は中央値55.5。
- **時期は「コメント欄の回が17:30に移った日」とそろう。**ただし同じ時期に動画の長さも変わっている（下の「追加1」）ので、どちらの影響かは分からない。
- 参考: 9/30 の回は19:24公開（ほかの回とずれた）で、3日目に897。ただしポストシーズンの日で、1本だけなので何も言えない。

### 5. 曜日・試合数・出場した日本人選手の数 → **支持しない（試合数は材料に無い）**

- **曜日**（B と C、28本）: 土150・日149・月147・火91・水61.5・木131・金83（各3〜5本）。決まった傾向は見えない。
- **出場人数**（`data/recap_history/` の `players` の数、B と C）: 6人以上 15本・中央値121、4〜5人 9本・中央値124、1〜3人 4本・中央値85.5。人数が少ない日がやや低いが、本数が4本しかない。区切りごとの人数の中央値は A 5人（材料があるのは8/24〜8/28の5本だけ）、B 6人、C 5.5人で、大きくは変わっていない。
- **試合数**: `game_count` が入っているのは 9/29 以降の材料だけで、比べられない。

### 6. 9月中旬のチャンネル全体のフィードの減り（`sources`） → **1段目は支持する。2段目は支持しない**

1日の再生（`sources` の流入の合計。各日について、その日を含むいちばん新しい集計の値）の中央値:

| 区切り | 流入の合計 | うちショートのフィード（`SHORTS`） |
|---|---|---|
| A 8/18〜8/28（11日） | 2,312 | 2,255 |
| B 8/29〜9/13（16日） | 769.5 | 707 |
| C 9/14〜9/26（13日） | 706 | 591 |

- 1段目（A → B）はチャンネル全体が約3分の1に減った時期で、17:00 の減り（916 → 162）と同じ向き。
- 2段目（B → C）ではチャンネル全体は8%減（フィードは16%減）にとどまるが、17:00 は64%減った。**チャンネル全体の減りでは説明できない。**
- 9/15〜9/17 は登録者からの流入（`SUBSCRIBER`）が135・89・60と、ほかの日（多くて43）より多かった。理由は材料に無い。

### 追加1. 動画が長くなり、平均視聴率が下がった → **一部支持（長いほど低い傾向。時期は1週間ずれる）**

| 区切り | 推定の長さの中央値 | 平均視聴秒の中央値 | 平均視聴率の中央値 |
|---|---|---|---|
| A 8/18〜8/28 | 35秒 | 26秒 | 69.0% |
| B 8/29〜9/13 | 46秒 | 19秒 | 33.6% |
| C 9/14〜9/26 | 75秒 | 21秒 | 28.5% |

- 見る秒数はほとんど変わらず、長さだけが倍になった。
- 8/15〜9/26 の41本を長さで分けると、50秒未満 23本の中央値397、50秒以上 18本の中央値114。ただし長い回は9月に集中しているので、1段目の時期の影響と混ざっている。
- 9/7〜9/13 は長さ57〜77秒でも中央値147、9/13（70秒）は442、9/14（86秒）は491だった。**長くなってすぐ減ったわけではない。**
- **推測**: ショートのフィードは視聴率の高い動画を広く流す、と一般に言われる。長さが倍になって視聴率が下がった分、流される量が減ったのかもしれない。材料では確かめられない。

### 追加2. 題の名前は材料のファイル順で、スコア順ではない → **見つけた事実（段差の原因ではない）**

- 題の名前（先頭の1〜3人）は、`data/recap_history/` の材料と照らせた37本の**全部**で、材料のファイル順の先頭3人と一致した。スコアの高い順（`morning_recap.contribution` で計算、今の17:00の並べ方）と一致したのは**37本中7本**だけ。
- 作り方: `scripts/upload_youtube.py` の `morning_who` は、渡された選手の並びの先頭3人をそのまま取る（並べ替えない）。
- 結果として、**その日に本塁打を打った選手が題に入っていない日が10日**ある（8/29 ヌートバー・岡本和真、8/30 ヌートバー、8/31 岡本和真、9/6 村上宗隆、9/10 村上宗隆、9/12 岡本和真、9/15 岡本和真、9/23 村上宗隆、9/25 鈴木誠也、9/26 ヌートバー）。
- 8月から同じなので2段目の原因ではないが、`render_intro_players` の注記にある「題に選手名があると再生が多い」という実測とも合わせて、直す価値があると見る（変更3）。
