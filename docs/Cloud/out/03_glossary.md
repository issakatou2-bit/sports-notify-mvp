# Cloud-03: 初心者向けの用語の注記の下書き

作成: 2026-10-04 クラウドのClaude（指示書 `docs/Cloud/Cloud-03.md`）。

本人の方針:「主対象はMLBをある程度見ている人。初心者向けの用語は、音声ではなく画面・説明欄で」。動画に出てくる用語ごとに、**画面の小さな注記（20字以内）**と**説明欄の一文（80字以内）**を用意した。

## 読む順番

1. **「用語の表」**: 29語。分類ごとに並べた
2. **「動画のどこで出すか（案）」**（いちばん下）: 決めてほしいこと
3. 「書き方の決まり」と「気づいたこと」は必要なときに

## 書き方の決まり（この表で守ったこと）

- 定義は **MLB.com の用語集**・**MLB.com のポストシーズンの説明**・**Baseball Savant** か、Gitにある材料（`scripts/` の中の説明）に合わせた。出典の無い説明は書いていない。
- 「OPS .900以上は一流」のような**数字の目安は入れていない**（公式の出典が見つからなかったため）。
- 出典のURLは、このクラウドの環境から**Web検索で題とURLが出たもの**だけを書いた（外部のサイトには直接つながらないので、本文は開けていない）。用語集の一覧で名前だけ確かめた語は「一覧で確認」と書いた。
- 文字数は、注記・一文とも句読点を含めて数えた（全角も半角も1字）。
- コレスポ独自のものは「独自」と書いた。

## 動画のどこで出すか（案）

いまの描画には、注記を置ける場所が2つある。

- **PSの回**（`scripts/ps_render_template.py`）: 表紙だけに「用語メモ」（下18%の上、幅420px・29px）。今は `ps_program.py` の `common()` が「WCS 2勝 / DS 3勝 / LCS・WS 4勝で決着」を入れている。
- **17:00の成績の回**（`scripts/generate_morning_short.py`）: 一覧の行に、場面の言葉の注記（`clutch_note`、24px）がある。

これに合わせた案:

| 出す場所 | 何を出すか | 理由 |
|---|---|---|
| PS予告・PSの話題の**表紙だけ** | その日の回戦の1語だけ（例: 地区シリーズの日は「地区シリーズ: 5試合制・先に3勝で突破」）。1回戦免除の球団が出る日は「1回戦免除」も | 今の3回戦ぶんの1行より短くなり、その日に要るものだけになる |
| 17:00の成績の**表紙（1人目の画面）だけ** | 「勝利貢献スコア: コレスポ独自の点数（公式でない）」 | 表紙にスコアを出しているので、独自の点数であることを毎回1か所で言う |
| 17:00の成績の一覧の行 | QS・HQS・猛打賞など記録の帯が付いた行だけ、帯の下に注記（今の `clutch_note` と同じ扱い） | 帯の略語（QS・HQS）で止まらないようにする |
| Savant・名前のある指標が出る画面（長編・話題の回） | その数字のすぐ下に注記1つ。三振率・空振り率の順位は「下位＝三振が多い側」を必ず添える | 9/30に「三振率リーグ下位1%」を取り違えた例が材料にある（`savant.py`） |
| **説明欄**（どの回も） | その回の画面に出た用語だけ、末尾に「用語」として一文ずつ（3つまで） | 音声では言わない方針。全部並べると長くなるので、出たものだけ |

## 気づいたこと

- サイトの用語集 `web/glossary.html` には「OPSは0.900を超えると一流」「ERAは3点台前半なら好投手」「WHIPは1.00を切ると支配的」といった**数字の目安が出典なしで書かれている**。この表では入れていない（指示書の決まり）。サイト側をどうするかはPCで判断してほしい（このファイルは書き換えていない）。
- `rarity.py` の BABIP の説明には「長く見れば.300前後に寄るとされ」とあるが、公式の出典を確かめられなかったので、この表では数字を入れていない。
- QS・ISO・BABIP は MLB.com の用語集の一覧に名前があることだけ確かめた（それぞれのページのURLは確かめていない）。
