# Cloud-08: 5大リーグのショート3つの型（情勢・明日の注目・今日のハイライト）の見本

作成: 2026-10-04 PCのClaude。本人（10/4）「五大リーグの方もちゃんとやっていきたい。今のシーズン情勢とか、明日の注目試合はもちろん、今日いちばん盛り上がったハイライトとか」。今は 19:00 の欧州サッカー（`scripts/generate_soccer_*`・`soccer_daily.yml`）、順位争い（`soccer_race`）、日本人選手の週末（`soccer_week.yml`）がある。

## 0章 最初に必ず

`docs/Cloud/Cloud-TEMPLATE.md` の0章の決まりに従う。読む順: `docs/Cloud/README.md` → この指示書 → 1章の材料。作業用ブランチは `cloud/08-soccer-formats`（セッションで決められていればそれ）。

## 1章 作るもの

### A. `docs/Cloud/out/08_soccer_formats.md`

1. **今の枠の棚卸し**: `.github/workflows/soccer_*.yml` と対応するスクリプトを読み、枠ごとに「いつ動く・何を材料に・何を出す・出ない日はどんな日」を表に。
2. **3つの型の設計**: (a) シーズン情勢（上位・CL圏・残留争い。リーグごと）(b) 明日の注目試合（選び方の条件。日本人選手の試合を優先）(c) 今日いちばん見られたハイライト（各リーグ公式YouTubeの24時間の再生数とコメント欄で選ぶ案。**取り方はPC側が実装**。ここでは選び方の条件と、画面・読み上げの構成）。各型の尺の目安、題の付け方、出さない日の条件。
3. 型ごとに「今の枠を直す／新しく作る」のどちらか、理由つき。

### B. `docs/Cloud/out/08_soccer_formats.html`

(a)(b)(c) の表紙と中身の画面を1枚ずつ（計6枚程度、1080×1920 を縮小）。材料は `data/soccer_race.json`・`data/soccer_preview.json`・`data/soccer_games.json`（Gitにあるもの）。(c) の再生数・コメントは材料が無いので、仮と分かる表示にする。安全域の重ね表示ボタン付き。

- 完成の条件: 棚卸しの表がすべての soccer_*.yml を含み、(a)(b) の画面の数字が材料と一致し、(c) は仮と分かること。

## 2章 決まり

- 材料に無いクラブ・選手・数字を作らない。推測は「推測」と書く。代表戦の期間は材料が無いのが正常。
- 見出しに読点で区切るキャッチコピーや不要な語りかけを使わない。日本人選手を前に出す。盛らない。
