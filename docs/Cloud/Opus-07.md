# Opus-07: 日本人選手のシーズンまとめを「概要→特筆スタッツと順位→深掘り→締め」の4段にするコードの下書き

作成: 2026-10-05 コレスポのPCのClaude（エマ）。

## 前提
- コレスポのコードは公開リポジトリ https://github.com/issakatou2-bit/sports-notify-mvp （ブランチ `main`）。**読むだけ。**取れなければ作業一覧を「保留」にして理由を書く。
- 成果物は作業をしているリポジトリの `collespo/` に、PRで出す。コレスポ側への取り込みは、コレスポのPCのClaudeが実データで確かめてから行う。
- MLB公式APIなど外部のサイトには通信できない前提で書く（コードは書いてよいが、検査は固定の材料で）。秘密は書かない。

## 背景
本人（10/4）「日本人選手の今シーズンまとめ、情報が局所的。広く概要をサラっと触れたあとに深いところへ。特筆すべきスタッツとそのランキング」。設計はクラウドがまとめた `docs/Cloud/out/07_season_structure.md`（4段の型・打者と投手の項目・台本の見本2本・足すべき材料の一覧）。今の作りは `scripts/season_topics.py`（`player_topic`・`league_rank`・`rank_keys`。順位は10位以内のときだけ残している）。

## 作るもの（`collespo/`）
1. `collespo/season_topics_v2.py`: `player_topic` と同じ入力から、4段の `items` を作る関数の下書き。
   - ①概要（試合・主な成績・球団の結末を1項目）→ ②特筆スタッツ（リーグ順位つき、**「○人中○位」を毎回**。規定到達者の中の順位は「規定打席到達者○人中○位」のように対象を言う。上位の項目から最大3つ）→ ③深掘り（Statcastのパーセンタイル・前年比のうち②を裏づけるもの）→ ④締め（材料にある事実だけ。年齢・自己最多など）。
   - 順位の母数を取るための関数は、MLB公式APIの `stats/leaders` か `stats?playerPool=...` を呼ぶ形で書き（呼ぶ部分は差し替えられるように）、検査では固定の材料を渡す。
   - 値が小さいほど良い指標（防御率・三振率など）は、順位の向きを取り違えない。「タイトル」は公式の表彰だけ。
2. `collespo/test_season_topics_v2.py`: 固定の材料（`data/season_topics.json` の鈴木誠也・今永昇太の値を使う）で、4段の並び・順位の言い方・向き・項目数を確かめる。
3. `collespo/README_season_v2.md`: `season_topics.py` への組み込み方、尺の目安、決めてほしいこと。
