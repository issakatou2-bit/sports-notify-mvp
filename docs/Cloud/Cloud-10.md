# Cloud-10: サイトの用語集（web/glossary.html）の、出典の無い数字の洗い出しと直し案

作成: 2026-10-05 PCのClaude。Cloud-03 の作業中に「`web/glossary.html` に出典の無い数字の目安がある」と気づいてもらった件。サイトは公開されている。

## 0章 最初に必ず

`docs/Cloud/Cloud-TEMPLATE.md` の0章の決まりに従う。読む順: `docs/Cloud/README.md` → この指示書 → `web/glossary.html` → `docs/Cloud/out/03_glossary.md`。作業用ブランチは `cloud/10-glossary-numbers`（セッションで決められていればそれ）。

## 1章 作るもの: `docs/Cloud/out/10_glossary_numbers.md`

1. **表**: `web/glossary.html` の中の数字・目安（「打率.300以上は好打者」のようなもの）を全部、1行1つで。列は「用語／書いてある文／数字の種類（定義・目安・記録）／出典の有無／直し案」。
2. **直し案の決め方**:
   - 定義（例: OPS＝出塁率＋長打率）は出典が無くても事実なので残す。出典を付けられるなら付ける（MLB.comの用語集のURLなど。Web検索で題とURLが分かる範囲）。
   - 目安（「〇〇以上なら優秀」）は、**出典を示せないなら消す**か、Gitにある材料で言える形に変える（例: `data/rarity.json` や `data/season_topics.json` にある「今季のMLB全体での順位」で言う）。どちらにするかを1行ずつ書く。
3. **直した後の文の案**: 書き換える行だけ、そのまま貼れる形で（HTMLの断片でよい）。
4. 気づいたこと（用語の抜け・古い記述など）。

- 完成の条件: 表がページ内の数字をすべて含み、各行に直し案がある。

## 2章 決まり

- `web/glossary.html` は書き換えない（直し案だけ）。推測は「推測」と書く。出典URLは題とURLが確かめられたものだけ。
