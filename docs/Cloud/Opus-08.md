# Opus-08: 欧州サッカーの「順位争い」と「明日の注目試合」を、日本人選手が前に出る形に直すコードの下書き

作成: 2026-10-05 コレスポのPCのClaude（エマ）。

## 前提
- コレスポのコードは公開リポジトリ https://github.com/issakatou2-bit/sports-notify-mvp （ブランチ `main`）。**読むだけ。**取れなければ作業一覧を「保留」にして理由を書く。
- 成果物は作業をしているリポジトリの `collespo/` に、PRで出す。コレスポ側への取り込みは、コレスポのPCのClaudeが実データで確かめてから行う。
- MLB公式APIなど外部のサイトには通信できない前提で書く（コードは書いてよいが、検査は固定の材料で）。秘密は書かない。

## 背景
本人（10/4）「五大リーグの方もちゃんとやっていきたい。今のシーズン情勢とか、明日の注目試合はもちろん」。設計はクラウドがまとめた `docs/Cloud/out/08_soccer_formats.md` の (a)(b)（「3. 直すか新しく作るか」で、どちらも今の枠を直す）。PLは10/10ごろ再開。

## 作るもの（`collespo/`）
1. (a) 順位争い: `scripts/soccer_race.py` に**降格圏の線**を足す下書き（リーグごとの降格の枠数は大会ごとの定数。5大リーグ分）。日本人選手のクラブを表紙の先頭に。`collespo/soccer_race_patch.md` に、差し替える関数と差分（diffの形）。
2. (b) 明日の注目試合: 選び方を「日本人選手のいる試合を先に、その中では出られる状態の選手（`soccer_availability.py` で離脱中でない）を先に」へ。画面は1試合1枚。`collespo/soccer_daily_patch.md` に差分。
3. 検査: `collespo/test_soccer_patches.py`。`data/soccer_race.json`・`data/soccer_preview.json`・`data/soccer_games.json` の形をまねた固定の材料で（**架空のクラブ・選手は架空と分かる名前に**）。
4. 気づいたこと（名簿のリーグの食い違い〔守田英正・前田大然・坂元達裕〕が選び方に効くか、など）。
