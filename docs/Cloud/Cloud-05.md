# Cloud-05: PSのトーナメント最新版と「初戦勝者の突破率」「LCSの組み合わせ」の画面見本（HTML）

作成: 2026-10-04 PCのClaude。本人（10/4）「今日のトーナメント最新版も出したい。過去の結果から、DSで先に1勝したチームが突破する確率とか、そのチームが突破したらLCSはどんな組み合わせになるのかとか」。数字の集計と本番はPC側（Codex）が行う。**ここでは画面の形だけを作る。**

## 0章 最初に必ず

`docs/Cloud/Cloud-TEMPLATE.md` の0章の決まりに従う（新しいファイルだけ、外部に通信しない、公開しない、秘密を書かない、拾い方）。読む順: `docs/Cloud/README.md` → この指示書 → 1章の材料。作業用ブランチは `cloud/05-ps-bracket`（セッションで決められていればそれ）。

## 1章 作るもの: `docs/Cloud/out/05_ps_bracket.html`

1080×1920 の縦長画面を縮小して**3枚**並べる（外部の読み込み無し、CSSも中に）。安全域（上8%・下18%・右13%）の重ね表示ボタン付き（Cloud-01 と同じ）。

| 画面 | 中身 | 材料 |
|---|---|---|
| 1 トーナメント最新版 | ア・ナ両リーグの勝ち上がり図（WCS→地区シリーズ→リーグ優勝決定シリーズ→ワールドシリーズ）。各シリーズの勝敗（例「1勝0敗」）、決まっていない枠は「未定」。日本人選手のいる球団に名前を小さく添える | `data/postseason.json`（`series` の `teams`・`wins`・`round`・`over`・`winner`、`players`） |
| 2 初戦勝者の突破率 | 大きな数字1つ（突破率%）と母数「○シリーズ中○」、本拠地で初戦勝ち／敵地で初戦勝ちの2本の棒、今年の初戦勝ち球団の札 | **数字はまだ無い。`--%`・`○` の仮の表示にして、仮だと分かる注記を画面の外（HTMLの下）に書く** |
| 3 LCSの組み合わせ | 「もし今リードしている球団が勝ち上がれば」の組み合わせを両リーグ1つずつ。条件つきの言い方（「〜なら」）。日本人選手同士の対戦になるなら一言 | `data/postseason.json` |

- 色・書体の大きさ: `scripts/ps-brand-theme.json` の `colors.stadium`、`scripts/ps_render_template.py` の見出しの大きさ。球団は略称バッジ（ロゴは使わない）。
- 文字の大きさの下限: 本文40px以上、注記32px以上（1080幅の座標）。
- HTMLの下に: 3枚それぞれ、どの材料のどの値を使ったか。勝ち上がり図の線をどう動かすと見やすいか（線が伸びる順番など）の提案を短く。
- 完成の条件: 3枚がそろい、1枚目と3枚目の球団・勝敗が材料と一致し、2枚目の数字は仮と分かること。

## 2章 決まり

- 材料に無い球団・数字を作らない。推測は「推測」と書く。
- 見出しに読点で区切るキャッチコピーや不要な語りかけを使わない（例「ワイルドカード初戦の日程」のように内容をそのまま）。
- 日本人選手を前に出す。盛らない。
