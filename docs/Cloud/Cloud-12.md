# Cloud-12: 検索から来ている動画の題の分析と、枠ごとの題の型の案

作成: 2026-10-05 PCのClaude。YouTubeの検索からの再生が増えている（1日の検索流入 9月上旬40〜100 → 9月末150〜370）。どの題が検索で見つかっているのかを調べ、枠ごとの題の型を提案してほしい。

## 0章 最初に必ず

`docs/Cloud/Cloud-TEMPLATE.md` の0章の決まりに従う。読む順: `docs/Cloud/README.md` → この指示書 → 1章の材料。作業用ブランチは `cloud/12-search-titles`（セッションで決められていればそれ）。

## 1章 作るもの: `docs/Cloud/out/12_search_titles.md`

材料: `data/analytics.json`（`days` の各日: `sources` は日ごとの流入元別の再生、`videos` は直近28日の上位200本の再生・平均視聴率など）、`data/published_videos.json`・`data/published_assets.json`（枠と動画ID・題）、`data/early_views.json`。

1. **流入元の推移**: 日ごとの検索（`YT_SEARCH`）・Shortsフィード（`SHORTS`）・登録者（`SUBSCRIBER`）の表と、7日ごとの合計。
2. **枠ごとの比較**: 枠（17:00成績・17:30現地の声・18:00報道・19:00予告・20:00情勢・21:00長編・資産動画〔殿堂・球場・球団〕・シーズンまとめ・試合の話題・欧州サッカー）ごとに、本数・再生の中央値・平均視聴率の中央値。**動画ごとの流入元は材料に無い**ので、「検索で見つかっていそうな動画」は推測として、長く再生が続いている（公開から日が経っても伸びる）動画を挙げる。
3. **題の型の案**: 枠ごとに、今の題の型と、案（検索される言葉＝選手名・球団名・「地区シリーズ」「結果」などを前に、読点で区切るキャッチコピーは使わない）。実例は材料の実際の題と数字で。
4. **試し方**: 1〜2週間で何を比べれば効果が分かるか（同じ枠の前後比較、比べる数字、本数）。

- 完成の条件: 1〜4がそろい、数字がすべて材料の値と一致している。

## 2章 決まり

- 材料に無い数字を作らない。推測は「推測」と書く。上位200本から漏れた動画は「○未満」と書き、0として数えたならそう書く。
- コレスポの主対象はMLBをある程度見ている人。日本人選手を前に出す。盛らない。
