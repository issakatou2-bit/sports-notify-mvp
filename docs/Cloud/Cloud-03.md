## 1章 作るもの → `docs/Cloud/out/03_glossary.md`

本人の方針:「主対象はMLBをある程度見ている人。初心者向けの用語は、音声ではなく画面・説明欄で」。動画の中に出てくる用語に、画面の小さな注記と、説明欄の一文を用意する。

材料（Gitにある）:
- `scripts/verify_terms.py`（いま検査している用語と正しい呼び方）
- `scripts/savant.py` の `LABELS`・`PITCHER_LABELS`（Statcastの指標の日本語名と説明）
- `scripts/rarity.py` など「名前のある指標」（アダム・ダン率など。リポジトリ内を検索して探す）
- `scripts/ps_program.py` の `common()` にある今の用語メモ（「WCS 2勝 / DS 3勝 / LCS・WS 4勝で決着」）

表の形:

| 用語 | 画面の注記（20字以内） | 説明欄の一文（80字以内） | 出典（公式の定義のURL。無ければ「材料のみ」） |
|---|---|---|---|

- 必ず入れるもの: WCS・地区シリーズ・リーグ優勝決定シリーズ・ワールドシリーズ・シード・1回戦免除、OPS・WHIP・防御率・規定打席・規定投球回、バレル率・ハードヒット率・空振り率・パーセンタイル（Savantの順位は「良し悪し」に揃えてあり、三振率の下位は三振が多い側、という注意も）、アダム・ダン率、勝利貢献スコア（コレスポ独自の点数で公式の記録ではない、と明記）
- 最後に「動画のどこで出すか」の案（例: PS予告の表紙だけ、成績の回の1人目の画面だけ）を短く

完成の条件: 20語以上。各語に注記・一文・出典の欄がそろう。

## 2章 正しさと書き方の決まり

- 定義は公式（MLB.com の用語集、Baseball Savant の説明）か材料に合わせる。出典が無い説明は書かない。
- 短く、言い切る。数字の目安（例: OPS .800以上は好打者）は出典があるときだけ。
- コレスポ独自のものは独自と書く。
