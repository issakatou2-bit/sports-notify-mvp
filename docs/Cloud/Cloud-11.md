## 1章 作るもの: `docs/Cloud/out/11_soccer_roster.md`

材料: `notability_engine.py` の `JP_PLAYERS_SOCCER`（手で書いた名簿）、`data/soccer_preview.json`・`data/soccer_race.json`・`data/soccer_games.json`（試合と順位表）、`scripts/check_soccer_roster.py`（名簿を確かめる道具の作り）。

1. **表**: 名簿の全選手を1行ずつ。列は「選手／名簿のクラブ／名簿のリーグ／材料の順位表・日程で見えるクラブのリーグ（見つかれば）／食い違い（あり・なし・材料に無い）」。
2. **食い違いの行**について、どちらが正しそうか。材料（Git）で言えることと、Web検索で題とURLが分かったこと（移籍の記事など）を分けて書く。**推測は「推測」**。
3. **直し案**: `JP_PLAYERS_SOCCER` の該当行を、そのまま差し替えられる形で（Pythonの断片）。確かめられなかった行は「要確認」として直し案に入れない。
4. `check_soccer_roster.py` が今回の食い違いを見つけられなかった理由の見立て（作りを読んで分かる範囲）。

- 完成の条件: 名簿の全員が表にあり、食い違いの行に判断と根拠がある。
