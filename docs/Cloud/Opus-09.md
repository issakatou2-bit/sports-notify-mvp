# Opus-09: 「過去の同じ状況」の話題を、リーグ優勝決定シリーズ・ワールドシリーズ（7試合制）と他の勝敗にも広げる

作成: 2026-10-06 コレスポのPCのClaude（エマ）。

> **コレスポのコードとデータ**: このリポジトリの `collespo/src/` にある写し（説明は `collespo/src/README.md`）。指示書の中の「`scripts/…`」「`data/…`」「`docs/…`」は `collespo/src/` の下のパスとして読む。`collespo/src/` は書き換えない。成果物は `collespo/` の下（`src/` の外）に作り、PRで出す。秘密は書かない。

## 背景
`scripts/ps_odds.py`（10/5作成）は、地区シリーズ（5試合制）で日本人選手のいる球団が2勝0敗・0勝2敗のとき、1995年からの同じ状況を数えて話題にする（例: 0勝2敗から勝ち上がったのは70チーム中7）。これから始まるリーグ優勝決定シリーズ（L、7試合制）とワールドシリーズ（W）でも使いたい。7試合制は状況が多い（1勝0敗・2勝0敗・3勝1敗・0勝3敗など）。

この作業環境はネットワークが Full なので、**MLB公式APIに実際につないで数えてよい**（`https://statsapi.mlb.com/api/v1/schedule?sportId=1&gameType=L&season=YYYY` など。鍵は要らない）。

## 作るもの（`collespo/`）
1. `collespo/ps_odds_v2.py`: `ps_odds.py` を元に、ラウンド（D・L・W）とシリーズの長さ（5・7）を扱えるようにした下書き。状況は「先に○勝」の一般形（a勝b敗になったチームが勝ち上がった数）。数え始めの年はラウンドごと（L・W は7試合制になった年から。年は公式データで確かめて書く）。延期の行（勝者の無い行）は数えない。
2. `collespo/ps_odds_counts.md`: **実際の数え方の結果**の表（ラウンド×状況ごとに、そうなったシリーズの数・勝ち上がった数）。**2通りで数えて一致させる**（例: シリーズの勝敗から／1試合ずつの記録から）。一致しないところは理由を書く。有名な例（2004年のレッドソックスの0勝3敗からの突破など）が表と合うか確かめる。
3. `collespo/test_ps_odds_v2.py`: 固定の材料（延期の行を含む）での検査。
4. 話題の題・項目の案（「日本人選手の球団が○勝○敗」のとき何を言うか）。予想と言わない・盛らない。
