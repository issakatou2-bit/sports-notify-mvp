# Opus-14: ショートのBGMの候補3曲（ライトで、YouTubeの動画のBGMとしてよく聞く感じ）

作成: 2026-10-06 深夜 コレスポのPCのClaude（エマ）。

> **コレスポのコードとデータ**: このリポジトリの `collespo/src/` にある写し（説明は `collespo/src/README.md`、main 341065c 時点）。指示書の中の「`scripts/…`」「`data/…`」「`assets/…`」は `collespo/src/` の下のパスとして読む。`collespo/src/` は書き換えない。成果物は `collespo/` の下（`src/` の外）に作り、PRで出す。秘密は書かない（APIキーなどは無い前提で、呼ぶ部分は差し替えられる形に）。本番のコードは直接変えない（取り込みはコレスポのPCのClaude）。

## 背景
10/6、新デザインのショートにBGMを付けた（`scripts/sound_mix.py` が声より20dB小さく重ね、声の間はさらに6dB下げる）。エマが `scripts/make_bgm.py` で5曲作った（`assets/bgm/`、試聴は mp3）。本人の感想:
- 4曲（スコアボード・ナイター・ダッグアウト・逆襲）は「質は高いが重い」。
- 「日常」（104 BPM・ハ長調、マリンバの旋律）は「ちょっと違う」。いまは仮にこれを使っている。
- 欲しいのは「**ライトな感じで、YouTubeのBGMに使われても違和感がないような感じ**。軽い音がメロディを奏でるタイプで、それでいて良さげ。長調（メジャー）。日常って感じ」。

## 作るもの（`collespo/bgm/`）
1. 3曲。どれも長調、110〜128 BPM、16小節（約30〜35秒）で継ぎ目なくループ、平均 -14dB。方向の例（どれか1つに寄せず、3曲で幅を出す）:
   - ウクレレ（または軽いアコースティックギター）の刻み＋口笛のような柔らかい旋律＋手拍子・軽いキック
   - グロッケン／ベル系のはずむ旋律＋はじくベース＋スネアのリムとシェイカー
   - 明るいピアノのスタッカートの旋律＋ピチカート＋軽いドラム（いわゆる「ほのぼの・ポップ」）
2. 作り方は `scripts/make_bgm.py` と同じ部品の考え方で、**この作業の環境で動く Python**（numpy・scipy、録音は VSCO 2 CE〔CC0〕を `git clone --depth 1 https://github.com/sgossner/VSCO-2-CE` で取れる。行40で取れることを確認済み）。表記の要る素材・生成AI・実在の曲の旋律や和音の流れの写しは使わない。
3. 声と重ねた確認: `scripts/sound_mix.py` の `mix()` で、声の代わりに 220Hz 前後の音を断続的に鳴らした仮の声と重ね、BGM が声の帯域（1.5〜4kHz）をふさいでいないか数字で確かめる（帯域の割合、山、ループの継ぎ目の段差）。
4. 成果: `collespo/bgm/<名前>.mp3`（160kbps）、作った Python（`collespo/bgm/make_bgm_light.py`）、`collespo/bgm/README.md`（各曲の BPM・調・楽器・構成・ねらい、数字の確かめの結果）。
