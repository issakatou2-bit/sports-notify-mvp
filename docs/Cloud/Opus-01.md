## 背景
本人（10/4）「長編は画面遷移とか移り変わりが無さすぎる。組み立てが雑」。今の長編（`scripts/generate_longform.py`）は、1920×1080 の画面の左右に立ち絵、下に字幕、中央に札（`_PANELS`: score / views / quote / stat / star / group / topic）を出すだけで、章の区切りも動きもほとんど無い。

これから長編を「構成表 → 章ごとの台本」に変える（`scripts/longform_plan.py` が構成表の形。`SCREENS` に画面の型が7つある）。**その画面の型を描くコードの下書き**がほしい。

## 読むもの（コレスポのリポジトリ）

3. `scripts/ps-brand-theme.json`（色）、`scripts/video_common.py`（`font`・`ease_out` など）、`scripts/review_render.py`（新デザインの書き方の例）

## 作るもの（作業リポジトリの `collespo/`）

### A. `collespo/longform_screens.py`
`SCREENS` の7つと、章の見出しカードを描く関数。どれも `(p, data) -> PIL.Image`（中央の札の部分、または画面全体。どちらにするかは `generate_longform.py` の今の配置を読んで決め、理由を書く）。`p` は場面の中の進み具合 0〜1。

| 関数 | 中身 |
|---|---|
| `headline_card` | 大きな見出し1つ（その日いちばんの出来事） |
| `player_card` | 選手の成績の大きな数字。打者: 打数・安打・本塁打／打点・四球・得点。投手: 投球回・被安打・自責／奪三振・四球・失点（死球があれば） |
| `ranking_table` | 順位表。1位・すぐ上・対象の選手（強調）・すぐ下と値、対象の人数（「276人中4位」） |
| `compare_bar` | 比較の棒（同じ単位の数字2〜4本） |
| `scoreboard` | シリーズの勝敗（球団名・勝数・日本人選手の名前） |
| `quote` | 引用（本文・出典・「翻訳」の表示） |
| `summary` | 締めの一覧（3行まで） |
| `chapter_card(p, title, index, total)` | 章の見出しカード。0.3秒前後のワイプで入って、見出しを出す |

決まり:
- **数字は渡された値をそのまま描く。**計算で作らない。投手の被安打と打者の安打を混ぜない。
- 動きは `06_motion_spec.md` から、カウントアップ・強調・章の見出しカードの3つまで。読む時間を削る飾りは入れない。
- 文字の大きさの下限: 本文36px、注記28px（1920×1080 の座標）。立ち絵・字幕・上の帯と重ねない。
- 選手名はカタカナか漢字（英字のまま描かない）。

### B. `collespo/test_longform_screens.py`
下の「見本の材料」で、各関数が画像を返すこと・大きさ・同じ入力で同じ画像になること（決定的であること）を確かめる。**日本語の書体が無い環境でも落ちない**ようにする（書体が読めなければ描画の検査を飛ばす）。

### C. 見本の画像 `collespo/samples/*.png`
書体が使えれば、見本の材料で各型を1枚ずつ（`p=1.0`）。使えなければ作らず、そう書く。
