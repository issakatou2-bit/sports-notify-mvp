**これは実装前の見本。** 数字とコメントは 8/29 に実際に取得したものだけ。
訳文も `local_voices.py` が実際に出したものをそのまま使っている。

想定は3分・16:9の通常動画。話者は2人。

## 最初に書いた見本（答え合わせ）を捨てた理由

先に「答え合わせ」で1本書いた。**他所に作れない中身だから**という理由で
選んだが、書いてみたら**週間成績の羅列**にしかならなかった。

```
14試合選んで、12試合が決着。そのうち5試合が1点差だった。
4件のうち、止まったのが3件、伸びたのが1件。
```

**「他所に作れない」と「面白い」は別のこと。** 答え合わせは算数で、
算数には人が出てこない。ハイライトとコメント欄には、
議論も冗談も苛立ちもある。**そちらを先にする。**

## 解説役の設定（敬語・有識者）

**話し方**：敬語。断定を避けず、しかし断定するのは事実だけ。

**言ってよいこと**
- 取得済みの数字と、その意味の説明（「15残塁というのは〜」）
- 翻訳したもの（出典を明示して）
- 一般に確立している事実（ロン・ギドリーの1978年防御率1.74）

**言わせないこと**
- 予想（「ドジャースは苦戦するでしょう」）
- 評価（「このコメントは的を射ています」）
- 渡していない知識からの断定

**「詳しい人」ではなく「調べたことを話す人」。**
上の台本で「1978年に防御率1.74を記録した投手です」と言えるのは、
それが確立した記録だから。**もし怪しければ、
「調べていません」と言わせるほうが、この設定には合う。**

## この見本で分かったこと

**1. コメント欄の対立が、そのまま構成になる**

苛立っているコメント（72件）と讃えるコメント（85件）が
同じ試合に並んでいる。**それを並べるだけで、番組の形になる。**

**2. ずんだもんの「それ、上がったって言うのだ？」が効く**

防御率0.05の話は、短編では説明する尺が無くて落ちていた。
**問える相手がいると、面白い所で止まれる。**

**3. 断りが会話になる（前の見本と同じ結論）**

「これは翻訳した言葉で、コレスポの評価ではありません」を、
解説が話の流れで自分から言っている。

**4. まだ直っていない問題が見えた**

上の材料は、**ハイライトとコメントが別の試合**になっている。
最も見られたのはアストロズ対ヤンキースなのに、
コメントはドジャース戦から来ている。
`fetch_youtube_comments` が上位4本から集めているため。

**長編にするなら、ここは1試合に揃える必要がある。**
短編でも以前から指摘されていた問題で、長編ではもっと目立つ。
