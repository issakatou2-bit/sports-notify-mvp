# PS2枠の切替と復旧

2026-09-28。本人の「戻せるようにしつつシフトを進める」に基づく実装。既存の19:00 dailyと20:00 morning_postseasonだけを更新し、本数・時刻・他枠・投稿台帳を維持する。

## 制作と投稿

- `ps_program.py` は公式全PS日程を照合し、予告は対象日全試合、情勢は確定勝数の差分を作る。開幕前はAL/NLの2カードずつ。試合がない日は予告を省略し、結果が変わらない日は情勢を省略する。
- 既存のVOICEVOX・投稿器・重複防止台帳・Bufferの動画配信を使用。追加の台本LLM呼出しはない。過去動画を作り直して二重投稿しない。
- 共通の色/書体と隅の胸上キャラを使用。初心者用語は画面/説明欄へ。題は所属する球団・回戦・第何戦を優先し、出場を断定しない。
- 対象試合IDを全画面まで保持。台本・題・画面の内容キー、音声manifestと台本の一致、描画文字の領域を検査する。日程欠落/前年混入/Final勝者不整合を停止し、WSの王手は世界一として表す。
- PS原稿の失敗は旧原稿への自動切替をしない。該当枠を停止し他枠を継続する。GitHub実行成功と各媒体の公開成功は別に確認する。

## 復旧の設定

GitHubのリポジトリ変数 `PS_PROGRAM_LAYOUT` を使う。設定のない場合は承認された2枠をv2で制作。

| 値 | 動作 |
|---|---|
| `v2` | 新しい共通画面とPS専用制作器 |
| `hold` | PSの2枠を止めて原因調査。他枠を維持 |
| `legacy` | 保存してある旧制作器へ手動で戻す。新版の失敗による自動復旧ではない |

旧版のPS表現/全カード保持を再検査せず `legacy` を選ぶことは推奨しない。まず `hold` とし、検証した修正後にv2へ戻す。日程欠落・勝者不整合など内容の検査は旧版への復旧時も取り除かない。

切替前のコードはmain e0b284d6b2a892493a40dd41f49cf178ae522362とGit履歴に保存。既存のgenerate_video.py・generate_morning_short.pyは保持し、共有コピーのClaudeの変更は上書きしていない。

## 確認手順

1. 固定資料のPS検査、全既存検査、Linux CIを通す。
2. `ps_program_preview.yml` は手動の制作確認だけ。定期起動・投稿・台帳書込みはしない。実公式資料の当日カード紹介と、翌日を想定した全4試合の音声付き動画を保存する。
3. 再現用は `rehearsal` と実取得日時を残し、投稿器で拒否する。公開に仮の時計や架空の結果を使用しない。
4. 実際のMP4・画面・音声の対応を確認してからmainへ接続する。導入日の実制作は当日の公式資料で再取得し、既存の投稿済み判定を外さない。
5. YouTubeの公開日時と動画ID、SNS各媒体の同一動画・本文・失敗・重複を個別に追跡する。連続3回に加え、休養/決着の境界を確認する。
