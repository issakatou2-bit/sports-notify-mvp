# 新デザインの共通の型（電光掲示板）

2026-10-07 本人「いま投稿されている新デザインを基本にした統一デザインにしたい」。
基本は 10/7 16:30 に公開した連勝の回（xbfpDJqtQUk、`scripts/review_render_v3.py`）。
どの枠も、**下の部品をそのまま使う**。枠ごとに変えてよいのは「真ん中の中身」だけ。

## 部品（すべて `review_render_v3.py` にある。新しく作り直さない）
| 部品 | 関数 | 決まり |
|---|---|---|
| 地 | `background(t, team_id)` | 球団色（`colors()` で暗く・色の強さを抑える）、2色目のピンストライプが流れ、照明が9秒に1回横切る。上に2色目の帯 |
| 見出し | `_header(d, 枠の名前, ページ)` | 左上に金色の「コレスポ」と枠の名前、右上にページ（1/3） |
| 球団の行 | `_badge` ＋ 文字 | 略称の札と「村上宗隆のホワイトソックス」 |
| 大きな数字 | `_reel` | Oswald。数字はスロットのように回って止まる。単位は日本語の太字 |
| 帯 | `intro` の tag | 金色の地に黒い文字。左から伸びる |
| 小さな札 | `_chip` | 2列×2段まで。右から飛び込み、勝ちは○が付く |
| 項目の札 | `_item_card` | 大（1つ目のかたまり・金）・中（数字と単位だけ金）・小（かっこ）。引用（「」・番記者）はクリーム色の札 |
| テロップ | `ticker(im, t, 文)` | 一番下（1486〜1574）に金色の帯が流れる。次の試合など |
| 出典 | `source(d, 文, 色)` | 立ち絵にかからない幅、2行まで |
| 立ち絵 | `presenter(im, t)` | 四国めたん（黒）を右下、テロップの上。声も四国めたん（話者2） |
| 効果音 | `cues()` | 案a。札の入場＝swish、数字＝roll/stop、○＝pop、引用＝notify、ページ＝transition |
| BGM | `generate_asset_video.DEFAULT_BGM` | 全枠同じ曲（本人が選ぶまで「日常」） |

## 動き（時刻表）
- 札の入場は右から、少し行き過ぎて戻る（0.45秒、`back_out`）。間隔 0.35秒。
- 背景は止めない（毎コマ描く）。

## 枠ごとの中身
| 枠 | 表紙（`intro` の v3） | 項目の画面 |
|---|---|---|
| 連勝・試合の話題・2勝0敗 | 済 | 済 |
| シーズンまとめ・シリーズの話題・殿堂入り | 題の言葉を大きく（済） | 済 |
| 17:00 成績 | 1位の選手：big=いちばん良い数字（0は選ばない）、unit=単位、sub=勝利貢献の順位、tag=その日の成績の行 | 2位以下を項目の札で |
| 17:30 コメント欄 | 試合の札（2球団と結果） | コメントを引用の札で（返信は小さく） |
| 18:00 報道 | 見出しの数の札 | 見出しを引用の札で（出典は札の上の小さい文字） |
| 19:00 予告・20:00 情勢 | 注目の試合：big=開始時刻、tag=何がかかる試合か、chips=勝敗と先発 | 1試合1画面で、スコアボードの中身を項目の札に |
| 長編（横長） | 同じ部品を横長に（Opus-18 の下書き待ち） | |

いま作ってある別の見た目（数字ドーンの色の塊、コメントの吹き出し、PS の独自の配置）は、この型に寄せて作り直す。
数字・言葉は材料にあるものだけ（足さない・言い換えない）。

## 今後に生きる決まり（2026-10-07 本人の指摘から。1回きりの直しにしない）
どの決まりも「共通の部品で守る」か「検査で止める」。新しい枠を作るときも同じ部品と検査を通す。

| 決まり | 守り方 |
|---|---|
| 何人も・何球団も出る枠は、地を**コレスポの色1つ**にする。球団色は1球団だけの回に限る | 部品: `background(t, None)`。検査: 複数球団の枠で team_id を渡していないか |
| 複数人は**1画面にまとめて**全体を先に見せ、そのあと詳しく | 部品: 順位表の画面（上位5人）。枠の構成表で「一覧 → 詳細」の順 |
| **読み上げている札を、その時に画面に出す**（読む順＝出る順、読んでいる札は明るく） | 部品: 札の出る時刻を読み上げの区切りから決める。検査: 読み上げの区切りと札の数・順が一致 |
| 同じ文（コメント・引用）を1本の中で2回出さない。**別の人が言い換えて書き写したもの**も同じ扱い | 検査: 画面に出す引用の重複。材料: `local_voices.drop_near_duplicates`（原文の語の並びが78%以上同じなら後のほうを落とす。10語未満は完全一致だけ） |
| 出どころの一言（「ESPN。」「〇〇の記者。」）だけの画面を作らない。次の引用と同じ画面で読む | 部品: `content_v3.source_lead` |
| 決まり文句の断り（「コレスポの見解ではありません」など）は読み上げない。出典は画面下と説明欄に | 検査: 読み上げにその文が無い |
| **安全域からはみ出さない**。入らない分は次の画面へ送る（積み増ししない） | 部品: 高さを測って画面を分ける。検査: 全画面の要素が見出しの下〜テロップの上に収まる |
| 意味の分からない記号を使わない（勝敗の「○」など）。文字で言う | 検査: 札の印は説明つきのものだけ |
| PS の予告は**全試合の一覧を先に**、そのあと注目の試合。情勢は**進行中の全シリーズ**を毎回 | 枠の構成表 |
| 下の帯は**番組全体で1本の時計**で流す。画面が変わっても頭に戻さない（10/8 試作で戻っていた） | 部品: `review_render_v3.set_program_clock`（動画を書く側が毎コマ呼ぶ）・切り替わりは `redraw_ticker`。検査: test_v3_rules |
| 締めは**共通の締めの画面**（番組表・チャンネル登録・音声の表記）。枠ごとに作らない | 部品: `review_render_v3.outro`・`OUTRO_TEXT` |
| 読み上げは画面の文の棒読みにしない。**めたん（解説）の話し言葉**を材料に持たせる（数字は画面と同じものだけ） | 材料の `speech`。検査: speech の数字が items の数字と一致 |
| 数字には**比べる相手を一言**（今季・ポストシーズン・自己最多など、公式の記録で数えたものだけ） | 部品: `ps_spotlight.context_line` の形を打者・ほかの話題にも |
| 一覧は**上位2〜3個を話し、残りは「画面のとおり」**。画面には全部（残りは小さく） | 部品: 項目の札の「小」 |
| 新しい見た目・構成は、**試作の画像か動画を本人に見せてから**本番に（切り替えは変数で） | 運用（AGENTS.md） |
