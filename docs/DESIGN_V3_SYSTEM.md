# 新デザインの共通の型（電光掲示板）

2026-10-07 本人「いま投稿されている新デザインを基本にした統一デザインにしたい」。
基本は 10/7 16:30 に公開した連勝の回（xbfpDJqtQUk、`scripts/review_render_v3.py`）。
どの枠も、**下の部品をそのまま使う**。枠ごとに変えてよいのは「真ん中の中身」だけ。

## 部品（すべて `review_render_v3.py` にある。新しく作り直さない）
| 部品 | 関数 | 決まり |
|---|---|---|
| 地 | `background(t, team_id)` | 球団色（`colors()` で暗く・色の強さを抑える）、2色目のピンストライプが流れ、照明が9秒に1回横切る。上に2色目の帯 |
| 見出し | `_header(d, 枠の名前, ページ)` | 左上に金色の「コレスポ」と枠の名前、右上にページ（1/3） |
| 球団の行 | `_badge` ＋ 文字 | 略称の札と「村上宗隆のホワイトソックス」 |
| 大きな数字 | `_reel` | Oswald。数字はスロットのように回って止まる。単位は日本語の太字 |
| 帯 | `intro` の tag | 金色の地に黒い文字。左から伸びる |
| 小さな札 | `_chip` | 2列×2段まで。右から飛び込み、勝ちは○が付く |
| 項目の札 | `_item_card` | 大（1つ目のかたまり・金）・中（数字と単位だけ金）・小（かっこ）。引用（「」・番記者）はクリーム色の札 |
| テロップ | `ticker(im, t, 文)` | 一番下（1486〜1574）に金色の帯が流れる。次の試合など |
| 出典 | `source(d, 文, 色)` | 立ち絵にかからない幅、2行まで |
| 立ち絵 | `presenter(im, t)` | 四国めたん（黒）を右下、テロップの上。声も四国めたん（話者2） |
| 効果音 | `cues()` | 案a。札の入場＝swish、数字＝roll/stop、○＝pop、引用＝notify、ページ＝transition |
| BGM | `generate_asset_video.DEFAULT_BGM` | 全枠同じ曲（本人が選ぶまで「日常」） |

## 動き（時刻表）
- 札の入場は右から、少し行き過ぎて戻る（0.45秒、`back_out`）。間隔 0.35秒。
- 背景は止めない（毎コマ描く）。

## 枠ごとの中身
| 枠 | 表紙（`intro` の v3） | 項目の画面 |
|---|---|---|
| 連勝・試合の話題・2勝0敗 | 済 | 済 |
| シーズンまとめ・シリーズの話題・殿堂入り | 題の言葉を大きく（済） | 済 |
| 17:00 成績 | 1位の選手：big=いちばん良い数字（0は選ばない）、unit=単位、sub=勝利貢献の順位、tag=その日の成績の行 | 2位以下を項目の札で |
| 17:30 コメント欄 | 試合の札（2球団と結果） | コメントを引用の札で（返信は小さく） |
| 18:00 報道 | 見出しの数の札 | 見出しを引用の札で（出典は札の上の小さい文字） |
| 19:00 予告・20:00 情勢 | 注目の試合：big=開始時刻、tag=何がかかる試合か、chips=勝敗と先発 | 1試合1画面で、スコアボードの中身を項目の札に |
| 長編（横長） | 同じ部品を横長に（Opus-18 の下書き待ち） | |

いま作ってある別の見た目（数字ドーンの色の塊、コメントの吹き出し、PS の独自の配置）は、この型に寄せて作り直す。
数字・言葉は材料にあるものだけ（足さない・言い換えない）。
