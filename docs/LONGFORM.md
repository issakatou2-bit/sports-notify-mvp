# 長編（対話形式）の設計

**まだ実装していない。** 数字が出るまで既存枠に手を入れない約束なので、
設計だけ先に固めて置いてある。実装は9/1以降。

---

## なぜ長編か

短編は7本あって、いちばん強い枠（日本人選手 55.4%）と
いちばん弱い枠（答え合わせ 15.2%）で3.6倍開いている。
足りないのは本数ではなく、1本あたりの中身。

長編の枠は**既にあって、死んでいる**。週次動画が2本で2再生。
新設ではなく建て直しになる。

そして短編と長編では、開かれ方が根本的に違う。

| | ショート | 通常動画 |
|---|---|---|
| どう出会うか | フィードで自動再生 | 題とサムネイルを見て選ぶ |
| 最初の1秒 | 全て。ここで決まる | 開く前に決まっている |
| 長さ | 35〜45秒が最良（実測） | 尺そのものが価値になりうる |
| 資産性 | 流れて消える | 検索で後から見つかる |

**フィードが無いぶん、題とサムネイルの比重が上がる。**
16:9のサムネイルは、ショートでは中央405pxに切り抜かれて使えなかったが、
通常動画ではそのまま出る。作った設計が無駄にならない。

## 2つの人格

### ずんだもん（聞き手）

既に音声として使っている。VOICEVOXの規約上、個人のYouTube広告収益は
「非商用の範囲」で許可されていて、公式イラストも使える。
著作権表記は不要（音声の「VOICEVOX：ずんだもん」は別途必要・実装済み）。

**役割は問うこと。**

```
「それって多いのだ？」
「なんでそうなるのだ？」
「それ、確かなのだ？」
```

**問いは主張ではない。** ここが設計上いちばん重要な点で、
ずんだもんは何も断言しない。だから事実の側の負担が増えない。

しかも**この形は誠実さを増やす**。いまは「翻訳したもので、
コレスポの見解ではありません」という断りを毎回読み上げていて、
定型文として流れている。対話なら、

```
ずんだもん「これ、コレスポが言ってるのだ？」
解説「いや、現地の記者が書いたことの翻訳。うちの意見じゃない」
```

**断りが会話になる。** 同じ内容が、はるかに届く。

### 解説者（語り手）

**名乗らせるのは口調と立ち位置であって、権威ではない。**

言ってよいこと:
- 取得済みの数字と、その言い換え
- 翻訳したもの（出典を明示して）
- 数字どうしの関係（「順位では上だが直近は負け越し」）

言わせないこと:
- 予想（「勝つでしょう」）
- 評価（「この補強は失敗だった」）
- 出典の無い背景（「◯◯は昔から△△と言われている」）

**「解説者だから詳しいことを知っている」という設定にしない。**
知っているのは、こちらが渡した数字だけ。渡していないことを
語り始めたら、それは設定ではなく捏造になる。

VOICEVOXの禁止事項にも「意図的な虚偽・誤解を招く利用」がある。
偶然だが、この設計と一致している。

## 題材（何を3分にするか）

手元にある材料だけで組めるものに限る。

### 1. ハイライトの回

**材料は全部ある。**

| 要素 | 出どころ | 状態 |
|---|---|---|
| 何のハイライトか | `mlb_buzz.topic_jp` | 実装済み（題を日本語に訳す） |
| 再生回数 | YouTube Data API | 実装済み |
| 試合結果・回ごとの得点 | MLB Stats API | 実装済み（スコアボード） |
| 目立った選手 | box score | 実装済み |
| コメント | commentThreads | 実装済み（翻訳つき） |
| 返信のやり取り | commentThreads replies | 実装済み |

短編では60秒に詰め込んで30.5%。**3分あれば、
試合の流れを追ってからコメントへ行ける。**

```
ずんだもん「今日いちばん見られた試合ってどれなのだ？」
解説  「パイレーツ対ドジャース。23万回」
ずんだもん「多いのだ？」
解説  「この日の2位が11万だから、倍以上」
　　　（スコアボード）
解説  「4回にドジャースが2点。ここで動いた」
　　　（コメント欄へ）
ずんだもん「現地の人はなんて言ってるのだ？」
```

### 2. 試合そのもの

**ハイライトと同じものとして扱う。** これは正しい判断で、
理由は「試合そのもの」の映像も文章も持っていないから。
持っているのは公式ハイライトという成果物と、その周辺の数字だけ。

別枠にすると、無い材料を埋めることになる。

### 3. 記事・トピックの回

**噛み砕き＋単語解説が効く。**

いま「現地の報道」は20.6%でチャンネル最下位のひとつ。
見出しを2件と番記者を1件、49秒で読み上げている。
**前提を知らない人には、固有名詞の羅列に聞こえる。**

対話なら、そこで止まれる。

```
解説  「大谷翔平の投手復帰が目前、と報じられている」
ずんだもん「投手復帰って何なのだ？」
解説  「肘の手術のあと、打者専念だった。それが戻る」
ずんだもん「じゃあ大変なことなのだ」
解説  「6件のうち4件、4媒体が同じ話を書いてる」
```

**単語解説の素材は既にある。** 資産動画34本が「日付に依存しない解説」で、
用語集ページもある。そこから引ける。

### 4. 数字の回（追加案）

勝利貢献スコアの中身、防御率とは、OPSとは。
**資産動画34本の中身がそのまま台本になる。**
31.1%と短編では健闘していて、3分にすれば検索でも生きる。

### 5. 答え合わせの回（追加案）

いま15.2%で最下位。**他所に真似できない唯一の資産**なのに死んでいる。

短編に収まらない中身だからかもしれない。
「◯連勝中だから注目、と書いた試合が実際どうなったか」を
7試合ぶん語るのは、45秒では無理がある。

**長編ならむしろ本来の形。** 対話なら「外れたのだ？」と聞ける。

## 実装に要るもの

| | 中身 | 難しさ |
|---|---|---|
| 1 | Haikuに対話台本を書かせる | 低。いまの `narrate_game` の形式違い |
| 2 | VOICEVOXを2話者で | 低。話者IDを引数にするだけ |
| 3 | 画面を16:9へ | 中。描画関数の座標を組み直す |
| 4 | 立ち絵を2枚置く | 低。公式配布を取ってきて貼る |
| 5 | 別ワークフローに分ける | 低。朝の回と同時に走らせない |

**3分＝4320フレーム。** いまの60秒動画の3倍で、描画時間もそのぶん。
GitHub Actionsの枠には収まるが、既存の回と同居させると危ない。

## 費用（実測から）

いまの1日の内訳。

| 呼び出し元 | 回 | 1日 |
|---|---:|---:|
| sanity（事実の検算） | 4 | $0.0098 |
| narration（試合紹介） | 6 | $0.0057 |
| reporters（番記者の訳） | 2 | $0.0043 |
| localize（多言語化） | 1 | $0.0041 |
| voices（コメントの訳） | 1 | $0.0035 |
| buzz（話題の要約） | 1 | $0.0017 |
| topic（題の訳） | 1 | $0.0003 |
| **合計** | **16** | **$0.029** → 月$0.88 |

**月$1かかる理由は、1つの高いものではなく16回の積み上げ。**
そして1位が `sanity`、つまり**書くことより検算のほうが高い**。
出力トークンは入力の5倍の単価なので、長い分析を書かせているぶん効く。

**3分の台本は$0.01。** 1日の検算とほぼ同じ額で、1本作れる。
費用は判断材料にならない。

## 5人に聞いた

### 戦略
週次が2本で2再生という事実を先に見るべき。長編の器は既にあって
使われていない。新しく作るのではなく、**なぜ死んだのかを先に**。
題材5案のうち「答え合わせ」だけが他所に無いもので、
残り4案は短編の焼き直しに見える。

### 伸ばす
フィードが無い＝**題とサムネイルが全て**。ショート7本で毎日
300回配られているのは、フィードが配っているからで、
長編にその追い風は無い。**最初の1本が0再生で終わる可能性を
勘定に入れる**べき。ショートから長編への導線（アウトロ、
説明欄、固定コメント）を先に作る。

### 経営
部品が倍になる。いま7枠で、今週見つけた壊れ方は全部
「緑で終わる静かな失敗」だった。**8枠目を足す前に、
既存の穴を数え直す**。描画時間3倍は、朝の回と同居させたら
タイムアウトの新しい原因になる。

### 作り手
対話は**尺を食う**。同じ情報を2人で言うと、1人より必ず長い。
3分に収まる情報量は、短編2本ぶんも無い。
**「長いから中身が濃い」にはならない**ことを設計に織り込む。
一方、断りを会話にできるのは本物の利点。

### 運営者
**「解説者は詳しい」という設定が、いちばん危ない。**
渡していない知識を語り始めたら、それは人格ではなく捏造。
ずんだもんが問う形は安全だが、答える側に歯止めが要る。
`sanity.py` を長編にも通すこと。

## 結論（いまの判断）

**やる。ただし順番を変える。**

1. **答え合わせを長編で作り直す**（5人のうち2人が指名した唯一の案）
2. ショートから長編への導線を先に作る
3. ハイライトの回は、そのあと

理由は、**答え合わせだけが他所に作れない**ため。
ハイライトも記事も、材料は誰でも取れる。
「毎日予告して、理由も結果も記録している」のはこちらだけで、
それが15.2%で埋もれている。
