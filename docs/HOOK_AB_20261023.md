# ショート導入のA/B（hook-20261023）

対象は `morning_press` と `asset:season_player`。Aは元の原稿・場面順。
Bは主見出しの次に同じ主役・論点の引用を置き、日付の音声案内へ戻らない。
選手まとめは、主役と画面の主成績に続けて、既存材料の自己最多または昨季比較の1指標を読む。
全札、出典、題、司会の割付、声の設定、描画部品、文字サイズ、動き、締め、公開枠は共通。
新しい事実・AI原稿は作らず、既存の事実照合・名前検査はそのまま通る。

## 起動と割付

- リポジトリ変数 `COLLESPO_HOOK_AB=on` のときだけ、2026-10-23以降の対象種類へBを混ぜる。未設定なら全A。この実装作業では変数を設定していない。
- 種類×JST公開日で固定したABBAの4日周期。種類ごとに1日ずらす。同日の同種は全動画が同じ条件。日付の偶奇にすると既存の毎日交代する司会と重なるため、ABBAで両条件に両司会を含める。
- 割付日は生成時の `--publish-at` のJST日付。時刻だけ/省略なら当日JST。材料の日付やアップロードのUTC日付では決めない。翌日予約はISO日時を指定する。
- 同じ主役・論点の引用、または選手の比較材料がない場合、割当BをAへ戻し `ab_assigned_variant=B` と `ab_fallback_reason` を残す。Aにも同じ基準の `ab_content_eligible` を記録し、falseの回は両条件とも効果判定から除外する（Bだけ材料の厚い日に絞らない）。
- `ab_enabled=false` は実験停止中/開始前、`ab_preview=true` は見本。これらは試験集計から除外する。`ab_variant=A` だけを条件に対照群へ混ぜない。
- 保存原稿には `hook_ab` を保持し、音声生成後・描画時に再割付しない。公開日が変わる場合は原稿・音声・動画を作り直す。

## 記録

実動画の隣に `<動画名>.mp4.hook-ab.json` を保存する。動画SHA256を照合してから公開記録へ結び付ける。
対象の `published_videos.json` の各行、資産動画ではさらに `published_assets.json` の各行に同じ記録を残す。
過去の動画へ遡ってラベルを付けない。受領記録のない従来動画は従来どおり。

- `ab_test`, `ab_variant`, `ab_enabled`, `ab_kind`, `ab_day`, `ab_rule`。
- `scene_starts`: 描画フレームから求めた場面の開始秒。同じscreenの連続台詞は一場面。v4の区間内の札・ページ切替も既存描画の識別子から記録し、単なる強調アニメーションは区切りに数えない。
- `dialogue_starts`: 合成単位ごとの `start`（音声結合開始秒）、`scene_start`（その区間の描画開始秒）、本文・話者・音声有無。
- `duration_seconds`: 実際の描画フレーム数から求めた総尺。

`dialogue_starts` は録音1区間の再生開始であり、文ごとの音素の発声開始ではない。VOICEVOX等の先頭の間は既存設定のまま。
描画は各区間をフレームへ丸め、音声は既存の秒数で結合するため、音声と描画の開始値はわずかに異なる。

## 保存材料の見本（公開しない）

写しのルートでPowerShellから実行する。`--render` を外すと原稿4本と実行コマンドだけを作る。
司会・見た目の既存設定をそのまま使う。両条件を同じ設定で作り、現在採用中のデザインで見比べる。

```powershell
& C:/Users/issak/AppData/Local/Programs/Python/Python314/python.exe -X utf8 scripts/preview_hook_ab.py --kind morning_press --render
& C:/Users/issak/AppData/Local/Programs/Python/Python314/python.exe -X utf8 scripts/preview_hook_ab.py --kind asset:season_player --render
```

選手は保存済みの先頭を使う。別の選手なら `--topic season_player_<ID>` を加える。
出力は `build_reports/hook_ab_samples/<種類またはtopic>/A/` と `B/`。
音声が作れなければ停止する。見本の受領記録は公開入口が拒否する。
材料取得、有料API、YouTube送信、変数の設定はこの入口にない。

音声を含む総尺と0〜3秒/3〜8秒の区切りは、本物の音声・動画で確認する。既存の尺計算・下限・上限は変更していない。
35〜45秒の目安を外れる材料では、Bだけ話速や札数を変えず、A/B共通の原稿編集を別途確認してから試す。
本人の見本確認後に、本人側で変数を有効化する。

## 判定

10/22の見本確認を受け、報道Bの表紙だけを修正。0〜3秒は主役と主見出しを96px・最大2行で表示し、3秒から既存の引用札で同じ見出しの全文へ続ける。日付と「現地の報道」は上の補足へ移動。長い見出しは縮小せず2行ずつ送る。Aと選手まとめの描画・順序は維持する。
字幕の90字打ち切りが次の文の「1年前」を「1」だけ残していたため、文末または数値の前で切る。音声原稿にある正しい数字は削らない。

10/23〜29は暫定評価。公開後72時間をそろえ、種類・司会・公開日を残して比較する。
主指標は8秒到達率と3→8秒の低下、補助は平均視聴率・再生数・登録/1000再生。
場面境界を曲線へ重ね、各種類・各条件6本未満なら期間を14日まで延長する。
同一ニュースの二重公開はしない。少数例の相関を因果と断定しない。
