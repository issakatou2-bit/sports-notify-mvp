# コレスポの実写素材

写真7枚と資料映像1本を2026-09-12に目視し、作者・個別の配布元・撮影時点・ライセンスを確認した。MLBと欧州5大リーグに関係する例であり、全選手・全クラブ・直近の試合を網羅するものではない。

`catalog.json` に出典URL、著作者、CC BYの版、変更表示、日付、SHA-256と容量を残す。原本はGit管理外の `build/licensed-media` に保存。取得先はWikimediaの承認済み配布ドメインだけに制限し、確認した版と違う内容は使用しない。

初期の自動処理はCC BY 2.0/3.0/4.0に限定する。CC BY-SAを一律に商用利用不可と判断したものではなく、別の条件を確認する素材は後から対応する。写真・映像の著作権以外に、人物の推薦・商標・音楽などの権利が自動的に付与されるとは扱わない。広告で選手がコレスポを推薦しているように使わない。

第2回の大谷選手の写真は2024年4月24日の資料。架空の二つの攻撃例を実際の大谷選手の試合だと見せない。ベルナベウは2009年・改修前、モナコのスタジアム写真は撮影日不明と表示する。

クルトワ加入紹介は、Real Madrid制作の2018年の映像をCommonsの個別ファイルとライセンス確認記録から採用。120〜126秒の6秒間を使い、原音を消し、クラブ表記も含む画面全体を残す。この1本の条件を、他のクラブ動画や試合ハイライトに拡張しない。

`python scripts/pilot_media_sampler.py --out build/media-sampler` は7枚・1映像の比較見本と出典付きHTMLを作る。FFmpegとPillow、日本語フォントが必要。原音・ナレーションはなく、外部投稿もしない。作者・ライセンスは画面内、個別出典と変更点は添付HTMLとテキストに記載する。

出典は各素材の `source_page`、条件は [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/) と [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) を参照。単に「YouTubeにある」「公式が公開している」だけの映像をダウンロードして入れない。
