# 観戦の見取り図（非公開パイロット）

最初の回は「CLと国内リーグは何が違う？」。1920×1080 / 30fps、四国めたんの音声、動く模式図、焼き込み字幕とSRT、専用サムネイルを作る。

## 作る

`python scripts/pilot_series.py preview --out build/pilot` で音声なしの画面一覧を確認できる。必要なのはPillowと日本語フォント。クラウドではNoto CJK、Windowsではメイリオを使う。

GitHub Actionsの「非公開試作 観戦の見取り図」を実行する。`upload=false`はファイルだけ、`true`はYouTubeへ非公開で投稿する。公開へ変更する入力や予約公開日時はない。毎週火曜17:17 JST頃にも、未投稿の確認済み原稿を1本だけ処理する。GitHubの都合で時刻が遅れることはある。

`status=ready`の原稿・出典・確認期限を検査し、VOICEVOXで1文ずつ合成する。実際の音声長から画面と字幕を配置し、音量・尺・画面サイズを確認した後に投稿。画像の文字があふれる、音声が無音、出典の確認期限切れなら投稿しない。

## 再実行

`auto`は既に投稿した回を飛ばす。結果は専用の`codex/pilot-series-state`ブランチへ保存する。台帳がpendingのままで動画も見つからない場合は、自動再送を止める。YouTubeの受領を調べ、台帳と照合してから再開する。結果不明のまま台帳を消して再投稿しない。

動画の差し替え試作では原稿revision、または`RENDER_VERSION`を上げ、新しい非公開版として作る。元の試作は削除しない。原稿・版が同じであれば2本目を作らない。既存の動画を公開に変更した場合も、非公開用の処理からは変更しない。

## 内容を広げるとき

この初版はCLの比較図・対戦相手・進出条件・観戦時の確認事項に対応する。別のテーマには新しい確認済み原稿と、その内容に合う図の追加が必要。ニュース選定や台本の無人執筆を実装したものではない。共通の音声・字幕同期、検査、非公開投稿は再利用できる。

現在の素材はコレスポ制作の文字と図のみ。試合映像・選手写真・球団の公式ロゴは使っていない。音声クレジットは動画末尾と概要欄に記載する。

公開リポジトリのActions artifactは非公開保管庫ではないため、ここには計画・検査結果・投稿IDの3種類だけを30日保存する。完成動画・音声・画面・台本の生成物は、リポジトリ自体が非公開の場合にだけartifactへ保存する。現在の公開repoで`upload=false`を実行した場合、映像は一時runner上で検査され、取得可能な動画artifactは残らない。所有者の非公開YouTubeで確認するか、ローカルで生成する。

初回の完成素材は共有PCの`build/pilot-20260912/result/`へ55ファイルを保存済み。YouTubeは`ICFFYySKugQ`、非公開。最初の全素材artifactはローカル原本照合後に取り下げた。公開repoへ非公開素材を追加しない。

## ストックと台本費用

`planning/topics.json`は企画候補で、完成原稿ではない。直下の確認済み原稿だけが動画生成の対象になる。現状の完成原稿は第1回の1本。未投稿原稿がなければ新作を作らない。

この番組の自動運転はAnthropic APIを呼ばない。`planning/cost-policy.json`に将来の生成案・試算を保存したが、課金処理は無効、予算も未承認である。新しい台本生成APIを有効にする前に、モデル・1本の概算・失敗時の再試行・月の上限をユーザーへ説明する。既存日次枠のAPI費用とは別に集計する。

日次の公開動画、公開再生リスト、Buffer、Web/PWA、Podcastにはこの試作を配信しない。`published_videos.json`にも登録しない。初回非公開というユーザー指示のため。
