# 見た目の失敗例

`failures.json` は合格すべき入力ではなく、指定した問題を検出すべき入力。
最初の6例は10/27のAPSCからの指摘。はみ出し・空き・今回見つけた配色遷移も追加した。
`example-layout.json` は同じ検査に渡せる配置例。

`tall-fullpage-repeat.png` は初回の長い画面の撮影失敗。末尾へ冒頭が繰り返して写っている。
サイトのHTML重複と混同しない。実際の画面を分割撮影して接合し、最後の部分まで画素の順序を検査する試験へ戻した。

`lineup-data.json` と `standings-data.json` は架空の表示試験材料。公開の成績や順位として使わない。
旧動画の不合格一覧と、ライト表示を引き継がない遷移画像は同フォルダに保存する。
今回の初回報告は `build_reports/visual_first_pass_20261027.md`。
