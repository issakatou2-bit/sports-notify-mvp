# オフ3種の公開文の回帰材料

samples.json はローカルの build_reports/offseason_samples_20261031/ に保存された material.json と narration.json の3組をそのまま複製したものです。予定は2026年11月1日制作分、賞とFAは2025年の過年度動作見本です。賞は公表内容をAPI形状に転記した材料で、実API受信とは扱いません。FAは既存の保存公式応答から選んだ3件です。

新しい外部取得・未発表情報・鍵・音声ファイルや個人パスは含めていません。検査は test_offseason_public.py。単語の途中の折返し、実際の吹き出しの基本48px（r3単体字幕42px）、幅・サイズ・行数別のページ計算、題・説明・音声欄・ハッシュタグと、対象外の既存出力の一致を確認します。
