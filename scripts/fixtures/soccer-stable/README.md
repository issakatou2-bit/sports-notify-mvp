# 通常出力の比較元

`success-narrations.json`は、起点465fcf1bの`preview_details`で保存材料6日分を組み立てた比較元。今回の変更箇所はこの関数と失敗時の記録・復旧のみなので、通常の台本全体をUTF-8・indent=2の文字列で比較する。

条件はCOLLESPO_SOCCER_LOOK=v6、COLLESPO_SHORT_LOOK=v4、COLLESPO_HOST_SPLITは空、話者metan、動きon。保存当時の開催期の締めを`review_render_v3.INSEASON_OUTRO_TEXT`に固定した。現行のオフ判定や雨衣の設定を書き換えるものではない。

6日分の試合材料の出典は`../soccer-daily/README.md`。これは今回の起点mainが生成する出力の比較であり、当日の完全な原稿原本・実音声・公開済み動画の復元とは区別する。
