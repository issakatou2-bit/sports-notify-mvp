# 公開前点検の回帰集

各JSONが独立した1件。`test_sanity_gate.py` が全JSONを自動で読み、実際の
`sanity.main()` の終了コードとhold recordを検証する。新しい誤停止はJSONを
1つ追加すれば試験対象になる。外部API・投稿APIは呼ばない。

```json
{
  "source": "元の実行URL・保存commit・調査記録など",
  "expected_held": false,
  "document": {
    "date_jst": "2026-10-25",
    "segments": [{"text": "実際の原稿"}],
    "sanity_materials": []
  },
  "issues": [{"kind": "事実の誤り", "severity": "high", "where": "実際の原稿", "why": "実際の指摘"}]
}
```

材料も1ファイルに同梱する。`sanity_materials: []` は材料不足を明示する。
材料の`source_url`・`retrieved_at`・日付は保存した値を保つ。人物名が前の行に
ある場合は、その行も`segments`へ入れる。断片だけを材料に合わせて書き換えない。
実誤りの対照は`expected_held: true`。原稿や材料を変えた作り物は`source`に明記する。
