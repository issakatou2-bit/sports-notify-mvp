# 週まとめの固定材料

Claudeが取得した `soccer_results.py --date` の出力（2026-10-27〜2026-11-02、取得2026-11-03）から、10試合だけを抜粋。出典はESPN、スコア照合はfootball-data.org。元の試合・個人成績は変更していない。

- 菅原由勢の先発・概算90分、鎌田大地の同週の途中出場と先発
- 遠藤航の出場なし、瀬古歩夢の分数不明の先発、坂元達裕の1得点
- 窓の境目は試験内で終了実時刻だけを差し替える。
- 順位7位・Liverpoolとの次戦は試験内の架空値。実際の順位・予定の根拠には使わない。

描画はリポジトリ同梱の日本語フォントを使う。通信・有料API・音声生成は不要。
